# humanize-writing · v0.48

面向文章、小说和剧本的创作与编辑技能。目标是清楚、有声音、有因果地完成作品；去模板感是其中一种编辑需求，不是把所有作品改到低检测分。

## v0.48：对白、叙述与回环的选择

[对白工艺](references/dialogue-craft.md)取消潜台词、动作和冲突升级的普遍优先级，保留有用的直接说明、署名、正式句和稳定互动。示例与练习同步修正，另添道具、接触或隐瞒须按场景设计处理，不能冒充等义润色。

[视角与声音](references/viewpoint-craft.md)允许文学叙述承载事件、时间与评论，不再要求删掉旁白后场景仍完整；明确影视交付仍遵守无旁白等具体稿约。[回环写法](references/narratology-craft.md)支持有功能的停滞、逐字复现和整段结尾，不强制觉醒或短句收束。[小说流程](references/novel-workflow.md)与[统一路由](references/routing.md)一起对齐，同时保留正文覆盖、情节承诺与连续性检查。

本版仅改七份文档，程序与lint规则版本0.43保持不变。历史案例与来源标签未全面重核；具体试用、文档复核和程序检查分别留证，不构成长篇稳定性或外部AI检测效果保证。

## v0.47：句子润色的意义保留

句子级指导取消抽象替换比例、每段意象、介词链长度、四选一关系动词、不可证伪就删除及否定词数量等机械要求。概述、感受、价值判断、被动句与常见用词按本句作用保留，不凭粗粝细节、词形或句式判断作者身份。

[编辑流程](references/editing-workflow.md)集中检查改前改后的范围、程度、归属与证据强度；[句层参考](references/sentence-discipline.md)提供具体例子，[视角指南](references/viewpoint-craft.md)保留人物何时发现、如何推测与是否确定的信息。新增症状入口接入[统一路由](references/routing.md)。

本版只修改指导文档，程序与lint规则版本0.43不变。历史资料引语没有全面重核；局部编辑试用与程序回归不能证明整体文学质量、长篇稳定性或外部AI检测效果。

## v0.46：舞台、发言与诗歌的适用条件

补齐[演讲稿路由](references/routing.md)，修正文体页正文与末尾速查表的冲突；发言不固定三点、短句、称呼次数或动员式结尾。诗歌保留有作用的直述、长行和原样复沓，炼字不按修辞等级或数量验收；用户指定的格律、押韵、对仗等形式仍须按约定核对。

舞台工艺允许有功能的独白、静默与重复，不要求每次上下场制造转折，也不用遮去舞台说明后的台词测试否决形体段。文本审读、真人桌读与场地排演分别记录；没有实测就标估计，普通文字委托不凭空增加排演门槛。

本版继续定向维护，程序与lint规则版本0.43不变；历史引文、格律示意表与资料来源标签并未全面重新查证。文档一致性及小型试用不能证明整部作品质量或外部AI检测效果。

## v0.45：保留判断与跨章修订

删减、情绪表达和改编新增内容的共同判断集中在[编辑流程](references/editing-workflow.md)，工艺页保留条件与示例。撤回仅按是否加重中心删段、情绪强制换动作、Show/Tell百分比、跨章轮换动作，以及记叙文收尾和克制程度的固定等级。教学另拟的细节不冒充事实不变的改稿；人物关系可以包含喜欢、需要与冲突，不用排除情感关系来说明其他维度。

小说转剧本按媒介、原作和实际稿约处理，不以三行上限或自动配烟杯道具代替场景判断。长篇修订沿现有项目机制追踪进一步受影响的后文，区分已核无需改、修后复核、待核和没有正文可查，见[长篇结构修订](references/longform-revision.md)。本版不重建项目系统，程序和既有测试保持，lint规则版本仍为0.43。具体跨章试用只证明当次范围，不等于几十万字长篇或长期连载已经验证，也没有外部AI率保证。

## v0.44：修正工整化与碎句的遗留指导

将为了对仗凑内容、段段套相同金句骨架的问题接入原编辑路由，见[对照、句段节奏与工整化](references/argument-and-rhythm.md)。普通叙述按内容展开，保留用户要求的对偶、必要比较、人物冲突和专业格式；不靠刻意参差或删除所有短句制造自然感。

修正网文的一长两短配方、记叙文默认短句连打、描写段必须快慢交替、蒙太奇固定镜头/行数，以及文风页八行加独句的反工整配方。人物弱点示例保留经历、行为与责任之间的区别，避免用一种原因排除另一种可能，也不为改稿补造创伤。撤回禁止点题及按开头形式判断作者身份的指导。

本版仅修改指导、示例和评阅提示；程序、既有测试与样稿不变。技能版本为0.44，lint的ruleset_version仍为0.43，未新增对仗率或计分项。文字效果须通过具体原稿、修订稿及保留项核读；这次维护不能证明外部AI率降低或整部长篇能力已经完成验证。

## v0.43：按内容分段，按证据用细节

段落长度与数字等锚点的正则匹配密度改为零权重观察，取消原6分/8分及高差异、高密度的认可标记。它们不能判断详略是否合理、细节是否真实或对故事有用；不能为降分重分段、添加无关数字地名，或把约数改成精确数。必要的数量、日期、地点和有功能的齐整段落继续保留，小说虚构细节按世界设定、视角与场景需要选择。

修正编辑流程、文风工艺和档案体中的相关残留配额，具体见[对照与句段节奏](references/argument-and-rhythm.md)。统计门槛、原正则、文体门控、其他权重、归一及25/40提示阈值保持。JSON版本为0.43，旧测试目录原稿保持不变。同文本跨版本降分仅说明规则变化，不是文学收益或外部检测结果；几十万字长篇、长期连载和完整剧集仍待作品级验证。

## v0.42：句长统计不再诱导改稿

句长标准差改为零权重观察，取消旧版的14/7分以及高标准差的认可标记；句长不设目标区间。句数门槛、文体门控、其他线索权重、归一方法和25/40提示阈值保持原样。JSON的ruleset_version为0.42。

仅改标点就能拉低旧分数，说明该指标可能诱导未证明有收益的拆合句。同时勘误历史交叉验证页的使用说明，撤回按标点配额、词汇丰富度和句长分布改稿的残留指令；历史研究数字未在本轮重核。本次修正不代表文字已经变好；保留新写与改稿的语义、声音和功能复读，也不按新分数倒改历史记录。更多试写片段仍属于模型辅助试用，不能替代完整长篇或目标平台检测证据。

## v0.41：对照与句段节奏维护

新写和改稿均复核无依据的贬一抬一、虚假二选一及短句过密，入口见[对照与句段节奏](references/argument-and-rhythm.md)。清理单向拆短句和固定收束句式的冲突指导，按事实、人物声音与文体功能判断。

lint取消“3–8字短句少于5%”的6分和重复“不是……而是……”的5分，两项仅保留零权重观察；JSON增加ruleset_version=0.41。其他权重、归一与退出阈值保持。历史分数属于当时规则，跨版本下降不能算文风改善、AI概率或外部检测成绩。本次不扩大长篇完结验证范围。

## 累计解决的问题

1. 分开新作、续写、评阅、标题、改编和多种交付物；中文剧本不再默认好莱坞格式。
2. 取消强制刷低分、固定比例删词、硬插第一人称/感官细节和非虚构可编不可核实经历的规则。
3. 修复台账报警：战力严重程度逐行判断；伏笔计划回收与唤醒提醒分开；缺文件、错表头和占位不能假绿。
4. 增加可运行项目管理：真实正文清单、修订指纹、交接、评阅证据、计划变更和完结检查。
5. 补进用户提供资料中的分集结构和中文格式，并区分重复来源、经验建议与待核实的平台/法规说法。
6. 再次清理文风专章中的固定配额、非虚构添经历和“AI味归零”承诺，补上声音契约及同稿前后对照。lint改用“静态命中较少/适中/较多”，JSON明确标记is_ai_probability=false；当时计分权重与退出码阈值保持兼容，修正“十分之一”、分钟和钟点表达中的程度词误报，逐项建议改为按声音与事实核读。
7. v0.39接收补编五六份文件，按两组同源正文去重，补入四类长篇问题的诊断、结构改动依赖、案例适配与收束计划。保留定长文学/类型小说和滚动连载的差异；教学示例不冒充真实作者修订档案，固定百分比和成败保证不变成执行指令。

v0.40继续审计并修复检测指导、历史数字口径、工艺强制配额和程序边界。当前外部分数验证入口见[检测证据与资料要求](references/detection-principles.md)；历史已测分数不能替代新版本运行结果。

## 可以做什么，验证到了哪一层

| 层面 | 当前支持 | 不应宣称 |
|---|---|---|
| 文笔与声音 | 按文体修订，诊断重复、空洞、视角和对白 | 低lint分证明好文笔或真人创作 |
| 小说架构 | 全书、分卷、章场目标，人物、规则与伏笔台账 | 有大纲就是写完整部 |
| 剧本创作 | 按媒介选格式，分集/分场到完整正文 | 文学剧本、拍摄稿、分镜是同一种交付 |
| 跨会话 | 保存状态、最近正文、实际事件、下一步与未决事项 | 模型凭记忆不会丢线 |
| 完结 | 检查正文覆盖、记录新鲜度、承诺处置和评阅证据 | 脚本能判断伏笔自然、战力合理或商业成功 |
| 验证 | 回归测试、微型作品闭环和独立操作评阅 | 已完成几十万字真实长篇试验 |

完整作品需要实际生成全部约定正文、逐章/集修订与终局回读。工具登记的assisted评阅是模型辅助评阅，不能写成真实人类读者背书。最终证据以具体测试记录为准，模板存在不计作产出验证。

## 使用项目执行层

以下路径占位需替换为实际路径，路径有空格时保留引号。脚本使用Python标准库，不要求安装编辑器hook或CI。

~~~text
python -B "<skill>/scripts/writing_project.py" init "<novel-project>" --kind novel --format web-novel --units 30 --title "作品名"
python -B "<skill>/scripts/writing_project.py" init "<screenplay-project>" --kind screenplay --format cn-tv --unit-type episode --units 12 --title "作品名"
python -B "<skill>/scripts/writing_project.py" status "<project>"
python -B "<skill>/scripts/writing_project.py" checkpoint "<project>" --next "接下来的具体工作"
python -B "<skill>/scripts/writing_project.py" check "<project>"
python -B "<skill>/scripts/writing_project.py" check "<project>" --final
python -B "<skill>/scripts/writing_project.py" complete "<project>"
~~~

init只接受空目录或不存在的目录，拒绝覆盖旧稿；初始化后是待填写项目，不是合格作品。先填作品bible、大纲与计划，再实际写正文、更新台账、建立checkpoint、记录有定位的评阅。完整命令和字段以 [project-workflow.md](references/project-workflow.md)及 --help 为准。

set-unit登记单元状态与摘要；review登记评阅来源和证据；resize变更目标单元数并要求原因；pause/resume保存断点；reopen重开完结后的修订。已有项目先读再接入，不能对非空目录直接init。

小说台账也可单独检查：

~~~text
python -B "<skill>/scripts/ledger_check.py" "<project>" --current-chapter 12 --current-volume 1
python -B "<skill>/scripts/ledger_check.py" "<project>" --current-chapter 30 --current-volume 1 --final
python -B "<skill>/scripts/ledger_check.py" --demo
~~~

ledger退出码：0为本次检查完整且无红线（可能有黄线），1为红线，2为检查不完整/数据或调用错误。空账需要有理由的显式声明，不把空模板当作没有问题。阈值是可调整的项目审计策略，详见 [模板说明](templates/README.md)。

项目工具退出码：0为相应操作成功或所查范围通过，1为未齐/过期/未通过，2为参数/路径/状态格式等错误；status的0只表示状态成功显示。工具不会在后台自动执行，也不生成正文或证明记录真实。

## 文本检查

~~~text
python -B "<skill>/scripts/ai_smell_lint.py" --genre fiction --json "<draft.md>"
~~~

历史脚本输出的优秀、合格、不通过是启发式分数标签。它不鉴定作者身份、不保证外部过检；剧本和诗歌没有专属标定。高分应核查是否属于正当格式，低分仍需读稿；只查不改不能自动重写。

v0.40新增--language auto/zh/en/mixed。auto不是自然语言识别器；中文不足100字时，未声明的ASCII文本仅作有限扫描，返回limited；单文件未判定返回退出码2。明确英文使用--language en，中英混语可用--language mixed。声明不是身份鉴定或校准保证。不支持的文字范围、短输入、读取或参数问题须读具体提示。批量输入中，若任一可判定稿超线，总退出码可为1，即使另有未判定稿；读取/参数错误仍返回2。应逐条检查status，不能用总退出码推断全部稿件已评估。--help正常显示帮助。

v0.40保留手工25/40提示阈值，没有为压低个别样稿调参；该版修正混语归一、末段选择和英文文体门控，因此受影响稿的分数可能变化。比较前后稿须固定脚本版本，不能把版本修复造成的下降当成文风改善。评测新增coverage和弃判统计；没有有效分母时输出N/A，而不是误称零误报。冻结语料重跑只属于回归。
