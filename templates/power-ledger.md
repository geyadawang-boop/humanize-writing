## 适用性与机器审计

- 当前适用状态选“适用 / 在场 / 活跃 / 当前 / 生效”之一；未来或退出状态选“未登场 / 计划中 / 未生效 / 退场 / 已退出 / 死亡 / 不适用”之一。不要把选项串当实际状态。
- “上次更新卷”记录已完成审计的卷号，例如 `第3卷`，不填未来卷冒充更新。当前适用角色的此列为空、无法解析或晚于当前卷，均为检查不完整。
- “生效卷”可选，用于区分已建档但尚未登场的角色；晚于当前卷的行不进入当前断档计算。未生效角色可以暂不填“上次更新卷”；生效时必须重新核实状态并填实际更新卷。
- 断档严重性**逐行**判断：落后当前卷1卷默认黄线、至少2卷默认红线；甲落后2卷不会把乙落后1卷一并升红。红线阈值可用 `--power-lag-red` 调整。
- 明确退出当前战力比较的角色不参与当前断档统计；仍应在人物/情节台账说明去向，不能为消除预警把活跃角色改成退场。
- 重复角色名、错列、空表和占位行会报告输入问题。脚本只查更新时效与结构，不能自动证明“越级有代价”“体系无膨胀”。

本作品确实无分级战力体系时，人工确认后在文件中另起一行写下声明；不要删除文件使检查静默跳过。代码块仅是示例，默认不生效；不适用声明不能与实际角色行并存：

## 每卷战力审计清单

- [ ] 本卷主角升级了多少？是数值变大，还是能力、技巧、认知变多？
- [ ] 新敌人与旧敌人的差距是否有已建立的规则依据？
- [ ] 若爆种或越级解决危机，代价是否具体写进了场面？
- [ ] 前期重要角色仍参与故事时，相对定位是否合理，有无无交代贬值？
- [ ] 新能力是在扩展旧规则，还是临时另起一套规则救场？
- [ ] 若突破天花板，是已铺垫的终局节点，还是剧情逼出的无代价例外？

## 膨胀预警与场景自查

出现形容词代替战术、配角全部失去作用、作者无法比较战力、敌人仅靠层级头衔变强等现象时，回 power-craft 的正反例重做对照。

每场关键战斗前检查：读者能按已知规则推演吗？越级的资源、身体、关系等代价可见吗？本书上限清楚吗？这些问题需要读正文，机器更新检查不能替代。
