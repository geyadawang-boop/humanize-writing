# 人物档案——{书名}

> 框架参考 character-craft.md 的语言档案、弧光与 plot-logic-craft.md 的动机分析。对需要持续追踪的角色复制区块，优先填写影响正文与连续性的事实；次要角色可简记功能。字段按作品适用，不为填满制造口头禅、创伤或成长。未决定写“待定”，不适用写原因；这与已由正文确认不同。

## 人物区块模板（按需要每人一份）

### 【人物名 / 稳定ID】

**基本设定**：年龄 / 身份 / 与主要关系人的联系 / 初次出现正文位置：

**动机视角（Want / Need / 恐惧，按需使用）**：
- Want：当前想要什么，在哪种情境下变化：
- Need：作品是否需要设计其未认识的需求；可不适用：
- 恐惧：实际影响选择的担忧或限制；可不适用：
- 已知与未知：该人物当前掌握什么，事实从哪一章/场获得：

**语言档案卡七项（用于对照语境中的声音）**：

| 档案项 | 填什么 |
|---|---|
| 口头禅/语癖 | 仅记录确实需要的习惯及使用情境；没有固定口头禅也可辨识 |
| 句长范围 | 平时与压力下的表达倾向，不按字数或句数配额写台词 |
| 常用词/禁用词 | 记录身份、关系或经历造成的用词偏好/回避及例外，不硬凑三个词 |
| 句法特征 | 陈述、反问、打断、转移话题等倾向及适用情境 |
| 话题偏好 | 什么处境中常提起什么；不要求每几句必绕回同话题 |
| 禁忌话题 | 如存在，什么会让其转移、沉默或改变措辞；保留例外 |
| 激动时语言变化 | 压力下表达速度、精确性、含蓄程度如何变化，也可保持稳定 |

**弧光（按本作品契约）**：
- 弧光类型：正弧 / 负弧 / 平弧 / 微弧 / 有意不变或其他；说明选择：
- 开篇信念与处境：确有“谎言”设计时再注明，不预设人物起初必错：
- 结局信念与处境：改变、坚持、退化或尚存张力怎样在正文呈现：
- 关键触发/动摇点（章节/场次号 + 事件；数量按实际）：
- 选择与代价：改变或坚持带来了什么后果；无必要时不强加创伤与损失：
- 若平弧或有意不变：信念如何受压、坚持或影响关系/环境；不要求必然改变别人：
- 完成证据：相关正文位置、关键选择及后果，未处理的部分与设计理由：

**前史（按相关性）**：影响当前行为、关系或信息的过去事实；记正文何处体现。可保留必要年表，不为“真实感”添加创伤配额。

**声音对读（可选）**：所选对话位置 / 评阅来源 / 发现 / 是否需改 / 保留理由。遮名仅帮助观察长期声口混同；相同职业、共同生活、模仿或有意呼应可能造成合理相似，不要求每句单独认人。

## 维护要点

- 人物性格、年龄、能力、伤病、知识、关系和物件以实际正文为据。新增事实、重大选择、阶段末或恢复续写时核对；有变化再更新，不为形式频繁改动。
- 声音由措辞、信息选择、关系与情境共同呈现。按需要抽读对话，不能靠每章塞口头禅维持一致。
- 弧光是否完成看作品提出的问题如何通过行动、关系和后果处理。正弧可以改变选择，负弧可以加深执念，平弧可以在压力下保持；“做相反的选择”不是统一验收条件。
- 事实、规划与推测分开标记；修改人物设定时检查受影响的后续章节/场次，并保留变更依据。
