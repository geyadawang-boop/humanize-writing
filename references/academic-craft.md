# 期刊与会议论文：学术语域的工程

用于写或改学术期刊论文、会议论文、投稿附件与审稿回复信。学位论文、开题与答辩走 [thesis-craft.md](thesis-craft.md)，不在本文件；通用语域判断见 [genre-router.md](genre-router.md)，本文件不重复它。

**先记住一条口径纪律**：本文件里出现的任何数字都属于某个具体语料或某个具体刊物。"某刊要求摘要不少于 350 字"与"另一刊要求不超过 250 字"可以同时为真；把任何一个写成"学术期刊的普遍要求"就是失真。写进稿件的每条"规范要求 N"都要留下它属于哪个刊物或标准。

## 1. 动笔前定四件事

1. **读者是领域内同行还是跨领域评审**，决定正式度取值。正式度是一条可调轴，不是单一档位：同一工作的期刊版与会议版可以取不同值。两个方向的偏差都要防——为显得学术而堆抽象名词，为"活人感"而插聊天腔。法律/伦理声明、试验方案这类冻结语域部件不适用本条。
2. **目标学科的元话语基线**。硬科学的自我指涉（we show / here we）密集且正常，部分人文学科更隐去作者。删连接词前先分类：篇章导航类通常保留，立场标记类按第 2 节处理。拿一份"删光 it should be noted"的通用清单通吃所有学科，是与证据相反的改法。
3. **目标刊物的摘要模型**：结构式（字段固定）还是单段散文式；中文自科学报多为结构式四要素，人文学报多为散文式提要。先定模型再写，不要在结构式刊物里塞叙事序。
4. **语域与惯例的层级**：标准本体 > 出版商与刊物细则 > 大学写作中心的二次解读。引用规范时按这个顺序取信。

## 2. 证据强度与语言强度对齐

这是学术文体最核心的"活人感"来源——不是句式花不花，而是每句话的确定性与它的证据链是否相配。

- 已测得的事实用确定陈述；外推到机制、因果、他处可重复性时用限定（may / suggest / 与既有研究一致）。中文对应"表明/提示/可能"与"本研究证实"。
- 对自身贡献的关键判断允许加强表述（demonstrates、establishes），前提是该结论确有支撑。**逐句自问：这句话的证据闭合了吗。**
- 两类常见反向错误都要查：把已经证明的结果也弱化掉（结论含糊会被退修），以及没有对照数据就用"证明/首次发现/重大突破"。
- 空隙陈述分三级并各配对应支撑物：可核查的检索性陈述（尚未被检验）、须有对立引文的陈述（结论不一致）、须有具体缺陷指认的陈述（存在方法缺陷）。真无争议时不要写"然而尚无人研究"——为了凑结构而虚构前人不足，属于编造。

## 3. 章节工艺

### 引言

按功能推进：建立领域（两步以内从宽背景收到具体主题）→ 指出空隙（gap / contrast / question 择一，并明确自己用的是哪一型）→ 占据空隙（目的、方法一句话、结构预告）。落笔时给每段标出它在做哪一步，防"只有背景没有空隙"的综述式引言。

失效场景：Letters 与短报告（引言常被压进首段或被摘要吸收）、高选择性刊物的单段叙事、人文学科的论证式论文（步骤顺序随出版语境变化，硬套会产出空洞的 gap 句）。**注意：宽背景拍本身不是套话**——需要删的是"不收窄的背景"，判断方法是看首段是否在两句内完成收窄，而不是看它有没有"随着……的发展"这几个字。

### 方法

结果之外最容易显出"是否真做过"的一章：交代材料来源、抽样与判准、可复现的处置顺序。方法清单式罗列（"本文采用定量与定性相结合的方法，保证研究结果的科学性"）的问题不是句式，而是没有任何可核对对象。

### 结果

一段一个可指认的趋势：报告数值 → 指出它相对研究问题意味着什么 → 把解释悬置到讨论。因果与机制一律留给讨论。用词从功能分组中取（存在、增加、减少、比较、归因），整段只用 show/suggest 会让重心消失。纯方法类论文的结果就是性能表，过度评论会被读作吹嘘；质性研究的发现与讨论常合并，不硬拆。数据不支持趋势时，不要为了"完整"补一句评论——那是越界解释。

### 图表

让图承载模式、表承载精确值、正文承载"为什么看这张图"。每个图注表注要能独立读懂（不看正文也能重建结论），正文引用图表时指向结论而不是复述数字。把表格内容用自然语言逐格念一遍是最常见的浪费，也违背"自明性"的用途。必要的术语重复保留，不因"避免重复"而删。

### 讨论

五步上行：一句重申主要发现（不复述结果数字）→ 与既有文献对照，同意与冲突都要指名 → 可能的解释或机制（按第 2 节配强度）→ **实质性**局限：说清它限制了哪一条推断的适用范围 → 具体的下一步。"样本较小，未来可扩大"这类不指向任何推断的句子，是形式化自我贬低，也是最典型的模板痕迹。讨论章不是第二遍结果。

### 结论

首段一到两句凝练主要贡献；中段按维度展开（理论推进 / 方法创新 / 实践应用，各维度逻辑独立）；末段局限与展望。总结已证发现用确定表述，阐释普遍意义用现在时，展望用将来或情态。不引入前文未定义的新概念。观点型论文的结论回到论证本身，不做汇总。

### 回复审稿人

按"意见原文 — 是否接受及依据 — 改动落在哪一页/行/图"三件事逐条写，同类意见先归并成少数主线。拒绝某条要给可判定的理由（数据不支持、超出范围、与稿件定位无关），不要用礼貌代替论证；致谢一句即可。**这一文体的立场强度允许高于正文**，把正文"保持克制"的规则套到回复信上会失去说服力；同一意见在多处换说法会让编辑无法核查。

## 4. 摘要：两种模型与共同的禁区

- 散文式单段摘要的常见职能序：通用背景（跨领域读者可读）→ 特化背景 → 本文结果的主句 → 与已有认识的关系 → 意义或推论（不得超过正文结论）→ 必要的方法细节。可用来自查的两条：结果主句之前不该出现别处已知的结论；最后一句的意义不得超过正文。"本文报告"式表述只在结果确由本工作产生时使用。
- 结构式摘要按刊物字段（目的/方法/结果/结论，或背景-方法-结果-结论）填写，字段固定时塞叙事序会造成重复。有具体刊物规定中文摘要"一般不少于 350 字"、关键词 3~8 个、以"；"分隔并按外延从大到小排列、点名"发展战略/关键技术/发展趋势"这类过宽词组不宜作关键词；也有刊物要求 4—6 个——**这些数字属于各自刊物**，取目标刊《投稿须知》。
- 共同的禁区（可在多家稿约中核实）：摘要不列参考文献编号、不放超链接；摘要里引入的缩写与术语须在后文重新引入；结果字段给样本量与均值/比例，不要只抛 P 值；阴性结果要写明，不能只报阳性。
- 关键词是检索接口，与摘要是两个对象：覆盖研究对象、方法、材料/物种/数据集等可被检索的概念，与标题和正文术语呼应，优先用受控词表词条。把关键词写成主题概括（越大越宽越好）没有检索价值。

## 5. 一致性管的是术语和格式，不是句式

house style 的约定覆盖术语、缩写、时态、数字与单位、引用标记，一次建立、全稿统一，多作者合稿时收益最大。**这条不适用于句式分布**：把"统一"执行成"全篇同构句"恰恰是模板化的来源；反过来，为了让句式"参差"而打乱主干，会破坏主位推进。

连贯靠信息推进，不靠连接词堆叠：每句开头承接上一句已确立的信息，句尾放本句的新信息，相邻句子由这种接力缝合。逐段标每句的末端焦点，若一段里焦点反复跳回同一元素，需要重组而不是加连接词。列表式方法步骤要的是平行而非接力，图注表注是自足单元，不套这条。机械套用会产生 this result / that finding 的指示词链，反而成了新的痕迹。

## 6. 学术文本的模板化特征

**有实证支撑的（只在该语料范围内成立）**：生物医学摘要语料（1510 万篇英文摘要，2010—2024）显示 2024 年若干风格词出现异常超额——稀有词的倍数高（delves r=28.0、underscores r=13.8、showcasing r=10.7），常见词的绝对差值高（potential δ=0.052、findings δ=0.041、crucial δ=0.037）；同一研究把 900 个超额词人工分类，实义词占 51.3%、风格词占 45.2%，且 2024 年的超额风格词里 66% 是动词。**这篇论文明说分析在语料层面进行，无法识别单篇摘要是否经模型处理。**另一项对 42% 被动与 100% 主动两个版本的对照实验未发现阅读速度或理解的显著差异；对五大医学期刊 297 篇论文、19,691 个被动结构的分析显示，指南带来的变化高度集中在方法与结果两节，并存在一组与被动强绑定的核心组织动词。另有检测工具把人类撰写的科学手稿判为机器生成的个案记录，以及跨检测器比较显示学生作文语料上的表现不可搬到期刊稿。

由此得到三条使用规则：① 不能把超额词清单当禁词表（它一半以上不是风格词）；② 不能由"含某词"反推作者身份，也不能由"改掉某词"声称降低了检测率；③ 被动比例与元话语密度是语体常态与学科惯例，把它们当缺陷会误伤正常学术写作。

**编辑共识（无对照实证，不得写成"AI 生成的标志"）**：首段背景不收窄；空泛展望与万能局限句；每段"主题句+三个并列支撑+因此"的齐整同构；结果段做因果论证；一次性抛出大量高级名词而后文不再使用；全篇均匀谨慎而与该节证据脱钩；连接词循环出现而命题间关系不明；摘要与正文结论不一致；回复信空洞感谢加全盘顺从；把本刊惯例当普适标准。

## 7. 被质疑"像机器写的"时该做什么

正确动作是补证据链与修夸大：数据、代码、草稿历史、文献溯源，以及把无支撑的强判断收窄。**不要用"降低某些风格词频率"或打乱句式来规避检测**——那既不改变问题，又损害清晰度，还违反本技能不承诺降检测率的边界。自检时可以把风格词清单当探针用：出现强判断词就回去确认有没有对应证据，而不是把它当写作禁令。
