# 校准报告：ai_rate 与 ai_smell_lint 的实测边界（v0.60）

本文件记录 **这一版到底测出了什么**，包括不好看的结果。所有数字都可以用第 8 节的命令复现。

配套阅读：[检测证据库](detection-evidence.md)（外部研究依据）、[语料清单](corpus-manifest.md)（数据来源与许可）。

---

## 1. 结论先行

| 问题 | 回答 |
|---|---|
| 同域内能不能分开人写与 AI 写？ | 能，测试集 AUC 0.924，但只限“中文问答/百科体、100–1400 字、ChatGPT 2022 回答”。 |
| 换一批语料还行吗？ | 不行。换到 C-ReD（学术/评论/作文，9 个现代模型）AUC 掉到 0.590，接近随机。 |
| 现有 lint 分数能当判据吗？ | 不能。同一批语料上 lint 分数的 AUC 为 **0.511**，与随机无异；它仍然适合“定位具体句子”，不适合“判断来源”。 |
| 能不能用来判断作者？ | 不能。模型输出是分布内的相似度参考值，不是作者身份概率。 |
| 能不能预测外部平台分数？ | 不能。没有任何一版做过外部平台对照实验。 |

一句话：**这次升级把“有依据的边界”补上了，而不是把分数做高了。**

## 2. 语料

来源：HC3-Chinese（CC BY-SA 4.0），中文同题配对（同一问题下的专家回答与 ChatGPT 回答）。构建脚本 `scripts/corpus_build.py`，产物在 `corpora/pairs/`，清单在 `corpora/manifest.json`。

| 切分 | 配对数 | 用途 |
|---|---|---|
| train | 3667 | 训练逻辑回归 |
| cal | 823 | Platt 校准（不参与训练） |
| test | 713 | 只用于报告指标 |
| 合计 | 5203 | — |

域分布（test）：百科 354、开放问答 307、金融 28、NLPCC 问答 20、法律 4。法律域样本太少，单域指标不作为结论。

切分规则：`sha256(pair_id)` 取模 1000 → 700/150/150，同一 pair 不跨切分；同一问题只保留一条，避免同题泄漏。人类与 AI 文本各自截断到 1200 汉字以内，隐私串（URL、邮箱、电话）已剔除。

排除：psychology、medicine 两个含个人健康披露的域默认不随包分发；可用 `--full` 在本地重建。上游 prompt 原文不随包分发。

## 3. 模型

| 项 | 值 |
|---|---|
| 模型 | L2 逻辑回归（全批量梯度下降，260 轮，lr 0.09，λ 0.008） |
| 特征 | 31 个可解释汉语特征，见 `scripts/features.py` 的 `FEATURE_SPECS` |
| 校准 | Platt scaling，在 cal 切分上拟合（a=1.0891，b=−0.0612） |
| 产物 | `models/zh_hc3_logreg_v1.json`（含权重、均值、标准差、指标、校准表） |
| 训练分布 | 中文问答/百科体；ChatGPT 2022 年回答；100–1400 汉字 |

### 权重最大的八个特征（标准化后）

| 特征 | 权重 | 方向解释 |
|---|---|---|
| long_sent_ratio | −0.667 | 长句占比越高，越偏“人写”侧 |
| para_len_sd | −0.546 | 段长差异越大，越偏“人写”侧 |
| sent_len_cv | −0.530 | 句长相对参差越大，越偏“人写”侧 |
| sent_len_mean | −0.421 | 平均句长越长，越偏“人写”侧 |
| para_len_mean | −0.416 | 平均段长越长，越偏“人写”侧 |
| second_person_per_1000 | +0.398 | 第二人称越多，越偏“AI”侧（此语料特有） |
| sent_len_sd | −0.390 | 句长标准差越大，越偏“人写”侧 |
| bigram_ttr | −0.368 | 二元组多样性越高，越偏“人写”侧 |

注意：这些方向是**这批语料的统计结果**，不是普遍规律。E19 的实验已经说明多数特征跨域会翻转；换语料训练，符号会变。

## 5. “AI 率”到底指什么

本工具输出的是：**在 HC3 中文问答分布内，这段文本与“AI 回答”这一侧的相似程度，经 Platt 校准后的 0–1 参考值。**

它不等于：

- 不等于“这段文字有 92% 由 AI 生成”；
- 不等于“作者使用了 AI 的概率”；
- 不等于任何平台的检测分数；
- 不等于“片段占比”（本工具按整段/分窗给分，不给“哪些字是 AI 写的”）。

分窗：超过 1400 汉字时按约 320 字切窗（最多 8 窗），每窗先做分布检查。异常窗不计入汇总，也不输出分数，只在 `window_checks` 保留原因与特征观察；其余有效窗口照常汇总。部分窗口被剔除时 `coverage_status=partial`，汇总只代表未触发异常规则的窗口，不代表全文；`full` 也只表示所有窗口都未被门控排除，不等于已确认属于训练分布。总分取有效窗口中位数与四分位距，特征贡献同取该中位窗，不再用整篇向量解释窗口分数。`window_checks` 逐窗列出状态、分数（仅有效窗）、字数与前 3 项贡献。全部分窗异常或声明文体不在分布内时，才整篇拒给分。窗口差异大，说明文本风格不统一；这本身是有用的编辑信息，但不是来源证据。

## 6. 外部集结果（不好看的部分）

| 集合 | n | 结果 | 说明 |
|---|---|---|---|
| 公版人写文本（鲁迅、朱自清等 11 篇） | 11 | 均值 0.138；`prose_luxun_yingdegaobie.md` 被判 0.94 | 真实误报。散文诗式重复与短句触发特征 |
| C-ReD 中文配对（跨语料） | 360 | AUC **0.590** | 学术/评论/作文，9 个现代模型；几乎随机 |
| 项目内 AI 校准样本（多文体） | 7 | 均值 0.303，最低 0.057 | 多数 AI 样本未被识别 |
| 同一 test 切分的 lint 分数 | 607 对 | AUC **0.511** | 规则加权分在这批语料上没有区分力 |

三条直接后果：

1. **不要把本工具当通用检测器。** 它的适用范围就是中文问答/百科体；`--genre` 只接受问答/百科的精确别名（问答、问答体、中文问答、百科、百科体、中文百科、qa、q&a、encyclopedia），小说、剧本、公文、学术以及混合、否定或未知声明都会返回 `status: out_of_domain`，拒绝给总分，只保留特征观察。未声明体裁时，只有全部分窗都有 6 个以上特征落在训练分布 4 个标准差之外，才整篇按分布外处理；个别窗口异常只剔除该窗，其余有效窗口照常汇总。
2. **lint 分数与 ai_rate 分工不同。** lint 负责“指出具体句子的问题”（可定位、可解释），ai_rate 负责“给出分布内的相对位置”（可校准、但有边界）。两者都不能单独判断作者。
3. **误报是结构性的，不是调参能消掉的。** E27/E29/E30 已给出理论解释：只要个体写作分布未知，误判就存在下界。

## 7. 使用边界

**可以用：**

- 同一批语料、同一体裁内，比较两份稿子的相对位置；
- 找出“哪些特征把分数拉高了”，据此核读句子（例如长句过多、二元组重复过多）；
- 在改稿前后做同一模型的对照，观察特征变化（不归因为“更像人”）。

**不可以用：**

- 判定作者、指控抄袭、作为学术不端证据；
- 预测知网/Turnitin/GPTZero/朱雀等产品分数；
- 对诗歌、剧本、公文、古文、翻译文本直接套用；
- 拿单次前后分数变化宣称“有效”。

**必须一起报告：** 模型名与版本、语料分布、文本长度、分窗数、有效窗数、分数与 IQR、是否分布外。整篇分布外时只报告 `status: out_of_domain`、拒给分原因与 `window_checks`，不报告分数；有窗口被剔除时，必须同时报告总窗数、有效窗数与剔除原因，分数首行写成“有效窗口参考值（x/y 窗）”，并注明 partial 不代表全文。只报一个数字属于误导。

## 8. 复现

```bash
# 1) 重建语料（需先取得 HC3-Chinese all.jsonl）
python -B scripts/corpus_build.py --hc3 /path/to/all.jsonl

# 2) 训练 + 校准 + 测试
python -B scripts/ai_rate.py train

# 3) 外部集评估
python -B scripts/ai_rate.py eval

# 4) 规则与特征证据
python -B scripts/evidence_measure.py --update-ledger

# 5) 单篇评分
python -B scripts/ai_rate.py predict 稿子.md --json
```

语料 sha256、各切分条数与域分布登记在 `corpora/manifest.json`；模型指标随模型文件一起保存，改语料必须重训并更新本报告。
