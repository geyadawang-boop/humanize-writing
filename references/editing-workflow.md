# 编辑与评阅流程

目标是文本更准确、具体、顺畅且保留作者声音。低 lint 分数不是目标作品的定义。适用于旧 A/B/C/D/F/G 模式。

## 1. 确定编辑边界

- 确认用户要改稿还是只评阅，要局部润色还是结构重写；明确的改写请求已构成编辑授权，无须再问“能否改真人文字”。
- 用 [genre-router.md](genre-router.md)确定用途、读者与语域。没有信息时从稿件合理推断；无法判断的保持原语域，不默认散文。
- 记录必须保留的事实、论点、叙事视角、人物声口、专业词和引用。虚构作品的新细节仍需和既有设定一致。改稿与评阅也应保留源文未确定的身份、关系和动机；一种可能读法须标为推测，不能当成原文已确认的事实。新增设定只在授权创作范围内设计。
- 非虚构缺具体材料时写得朴素即可，不能编出“上周在走廊闻到消毒水”等经历来增加真实感；引用必须保持原意，直引不擅改。

## 2. 先诊断再下笔

优先找影响最大的两类问题：信息缺失/重复、因果不清、结构失衡、语域错配、动作不具体、节奏单一、声音混同。每个判断用原文位置或短例子支持。出现无依据的贬一抬一、虚假二选一、碎短句或过度工整时，按[对照、句段节奏与工整化](argument-and-rhythm.md)检查实际关系、动作链和停顿，也检查相邻段落是否在重复同一套金句或起收结构；核对原有事实与声音后再改。

**三条快速诊断（先做这三步，再动词语）**

1. **段首句连读**：把所有段落的首句单独抽出来连起来读。如果它们自己就构成一篇连贯摘要，说明结构是模板长出来的，不是内容长出来的——**先改结构再改词**。词表和句式层面的修复对这种问题无效，改完仍然读着像套式。
2. **空洞处只有三种正当出口**：某句需要材料里没有的细节、数字或经历时，只有（a）向用户提问索取，（b）把这句改写成不依赖该细节的更简单说法，（c）删掉这一处。**不得用"合理的具体情况"填补**——这是编造的最高发入口，也是"人味"最容易滑向表演的地方。缺什么就标出来（如 `[待补：真实结果与比较口径]`）。
3. **保护片段逐字回扫**：改完一轮后，核对下列内容是否仍**逐字**出现在输出里：数字与单位、日期与时间、版本号与路径、专名与缩略语、直引的原话、以及范围和程度限定词（约、十余、在……条件下、多数）。中文里数字与单位之间没有词边界，回扫要按整串匹配而不是分词后比对。命中不到的项回到原稿取，不靠记忆重打。

**只查不改**：输出“位置 → 问题 → 为什么影响读者 → 可选改法”，有必要区分高优先级和润色项，随后停止。不得写回原文件。

**改稿**：先改意义和段落关系，再改句子。局部请求只动所需范围。结构改变较大时保留可回溯版本；用户只要成稿时直接交付成稿。

长稿涉及中段、人物漂移、情节重复或结尾承诺时，追加[长篇结构修订](longform-revision.md)：用实稿建立问题证据，记录前后依赖与修改副作用。只收到选段时，仅就该范围下结论；不能拿局部修订当整书核验。

### 文风提升：先定声音，再比较效果

从原稿或明确需求确定一张简短的声音契约，不必另建文件或向用户重复提问：叙述人称与距离、用词语域、句段节奏、情绪外露程度、意象来源、不同人物的说话习惯。没有充分信息时保留原稿可辨的选择；不要把所有文本统一成冷笔、短句、口语或物件收尾。

先记录不可改的事实、立场、人物动机与必要格式，再选择一至两个影响阅读的维度。按 [style-craft.md](style-craft.md)和[文风光谱](style-spectrum-craft.md)尝试有依据的改法；按动作、视角、句法、意象或信息次序改善，不靠堆“手法数量”。

需要验证提升时，保留同一篇原稿和修订稿，分别检查：信息是否更清楚、表达是否更具体、节奏是否服务内容、声音是否可辨、是否新增冗余或削弱情感。每项指出文本位置；允许“有得有失”或“无改善”，不填写预设满分。必要时匿名交叉读稿，评阅来源如实标assisted/human，不将模型盲读说成人类实测。

非虚构的事实、数值、范围、因果强弱、立场和引用，以及剧本人物动机与冲突立场，均需逐项对照。事实或声音损失时先修复，即使lint下降也不能称整体改善。已有格式契约中的标题、条目、术语与重复可以保留。

## 3. 有效的修改动作

### 删改前先核对会失去什么

本节是各工艺页共同使用的保留判断。试删一句、一段或一场后，检查事实和限定、人物声音、因果与知情状态、时间空间定位、情绪体验、后续铺垫是否受损；没有强调中心不等于没有作用。能用移位、压缩或消除重复解决时，不必整段删除。判断存疑可保留或提出方案，不能因“能删”就当作“应删”。

替换词语、调整语序或拆合句后，回看否定的对象与范围、数量和程度、时间与完成状态、消息来源、人物判断归属及因果强弱。流畅不能补偿意思变化：未证实不能变成已否定，关联不能变成导致，人物的猜测不能变成叙述事实；未知行动者也不能为改主动句而补造。疑似句层问题再读[句子级编辑](sentence-discipline.md)，不把这份检查变成每段必须附带的解释。

直接感受、内心活动、概述和动作描写都可承担信息与情绪，不固定展示比例或身体动作数量。非虚构与保真改稿只采用材料已有或可核的事实；一个情绪词不授权补吸烟习惯、药物、疾病、创伤或细微动作，也不能从单个动作反推唯一心理。授权新作可以设计细节，仍须符合设定和视角。

改编先确认某句在原作承担的作用，再按媒介选择动作、表演、对白、旁白、字幕或声音。新设动作若改变习惯、动机、责任或道具连续性，须按原作约束与改编授权取舍；必要时列为方案，不能把教学另拟版当作事实不变的示范。纯格式转换只处理格式，不借机重写情节。工艺页里的替代写法均服从这些边界。

| 观察到的问题 | 可采取的动作 | 保留边界 |
|---|---|---|
| 抽象评价没有信息 | 恢复材料中已有的动作、对象、结果；或删除空判断 | 缺证据时标缺失，不虚构数字/场景 |
| 无依据的否定前项、抬高后项 | 直接陈述有依据的主张，或恢复并存、条件、程度关系 | 真实纠错、必要比较及人物争执按功能保留 |
| 连续短句割裂语义 | 按动作、观察、因果与指代合并紧密信息，调整主干及停顿 | 不补动机或因果；对白、诗歌与剧本拍点不按比例合并 |
| 为工整凑两半金句或重复段落骨架 | 删去无信息的重复，按真实关系展开，恢复被口号挤掉的事实 | 不为参差制造碎句；保留指定对偶、有效比较及便于核对的格式 |
| 长句主干被压住 | 调整主语、宾语、修饰范围，按意义拆分 | 不要求三个长句必插短句 |
| 连接词多但逻辑空 | 修复实际因果/转折，再删冗词 | 必要路标、技术步骤保留 |
| 段落篇幅或重复结构与内容功能不合 | 按每段功能收放，删同义重复 | 平行结构服务比较或节奏时保留；等长或不等长本身不要求修改 |
| 文风过分圆滑/通用 | 恢复作者真实判断和具体措辞 | 不强插第一人称、错字、矛盾或口头语 |
| 修辞密而无新意 | 用准确动作或一个有效意象替代 | 不对诗歌/人物台词套统一比喻配额 |
| 前文承诺未兑现 | 补证据/场景，或收窄承诺 | 不能用“意犹未尽”掩盖缺结论 |

按症状查 [routing.md](routing.md)，快速清单见 [quick-reference.md](quick-reference.md)。需要按文体做分层文本评阅时查 [detect.md](detect.md)。需要更细的结构、连续性与文本复读方法时，可按需查 [self-check-workflow.md](self-check-workflow.md)；它是功能性工具箱，不是额外轮次、固定分数或外部送检门槛。

## 4. lint 只作可选线索

用户明确要求机器检查、文件可读且工具可用时，可运行 ai_smell_lint。常规短句、标题、诗歌、剧本及急稿不强制跑分。

```text
python -B <skill>/scripts/ai_smell_lint.py --genre academic --json <file>
```

支持 general、tech、academic、official、law、email、speech、fiction。按文本实际功能选；不为降低分数改选 genre。不存在 screenplay/poetry 模式，不把它们伪称已校准。

- 0/1 是脚本阈值结果，不是作者身份、发表许可或文学品质判定。2 包括输入不足、语言未确认/范围不支持、读取失败和参数错误，需读消息；limited/unsupported/short不能写成检查通过。批量中可判定稿超线时总退出码可为1，即使另有未判定稿，须逐条查看status。
- language支持auto/zh/en/mixed；auto不是语言识别器。英文或明确中英混语用--language en或mixed声明，声明不代表语言已验证或模型已校准。前后比较固定脚本版本、文体和语言处理；v0.40的混语计分修正不与旧版直接作降分对比。
- 对每项命中判断是不是有效功能；法律术语、程序步骤、重复母题可能正当。
- 小于40的得分不能证明自然，高分也不自动要求重写；保留正当命中并解释即可。
- 单次局部润色默认最多两轮有依据的改动；没有可证实的改进就停止，不无限循环刷分。长篇分批修订及尚未解决的事实、结构、连续性问题仍按交付范围处理，不被此局部上限截断。
- 外部送检、上传全文和付费不属于本地编辑的默认流程；只在用户明确要求该动作时执行。平台价格/规则先查当时官方说明。

## 5. 交付前核对

核对事实/引文/专名、原始目标、逻辑、语域、格式和遗漏。创作稿另核视角、人物声音、具体动作与结尾效果；检查编辑是否新造了对立、把可并存项写成排斥关系，把连贯句群切得过碎，或将每段都润色成相同的对仗结构。只报告实际做过的朗读、工具运行或人工检查；没有声音工具时可做文本口读模拟，但不能声称完成真人朗读或听众验证。

**再往回看一遍：本轮改动自己有没有变成新毛病**。过度修正是独立的一类失败，不是"改得多"的中性结果。逐项反问：有没有加没有根据的口语词、表演性的犹豫与自纠、为了让节奏"参差"而随机改变的句长？有没有把原来不规则但准确的句子磨成更顺、更整齐的版本？有没有为"人味"补出材料里没有的反应、感叹或细节？任何一条成立就退回该处。**没有可证实的问题时，返回原文就是合法交付**——干净而不规则的稿子不需要被改出东西来证明工作做过；此时报告"未发现需要修改的问题"，并说明查了哪些位置、用了什么判据。

冷却一夜、删减10%、读者试读等是可选工艺，不是当前交付必须等待的条件。用户要求严格审稿时加深事实与结构核查，并明确未核实项，不虚构检测或专业审核结果。

交付修改稿；必要时附少量实质变化。用户要逐条记录时才给完整改动表。只要正文的任务不附规则讲义。
