# 自查与修订流程

这是[编辑与评阅流程](editing-workflow.md)的按需工具箱。以任务范围、文体和正文证据选择方法，不要求每稿跑遍清单。严格评阅意味着更细致地核对文本，不意味着必须低分、词表零出现、句长随机或交付前等待数周。

## 七步流程（按任务取用）

### 第1步：确定范围并换阅读视角

记录用户要的是整篇、整书、单章、一个场次还是局部润色，以及必须保留的事实、设定、声音和格式。只收到选段就只评价选段，不把局部检查写成整部完结核验。隔夜、换字体、打印或从中段开始重读可以帮助发现盲点；没有时间时直接完成当前能做的检查。

### 第2步：检查意义与声音

看信息、逻辑、事实、具体行动与语域。先指出原文位置和读者可能受阻的原因，再判断要不要改。朗读或TTS在可用且有帮助时采用；文本口读模拟不冒充真人朗读或听众测试。

### 第3步：按文体检查

使用[快速清单](quick-reference.md)和[文体路由](genre-router.md)的适用检查点。保留有功能的术语、列表、排比、重复母题、必要总结与作者声音。小说、网文与不同媒介剧本各按作品契约核对，不能互套句段或情节配额。

### 第4步：可选本地 lint

用户要机检时按实际文体和[编辑流程](editing-workflow.md)运行ai_smell_lint。0/1仅是工具阈值，2需读输入/参数说明。命中须回到上下文；低分不证明写得好，高分不证明由AI创作。不能为消警报删除有效表达，也不能按分数无限回改。

### 第5步：核实证据与来源

数字、引文、专名、设定与原始材料逐项核对。非虚构不能添加无来源的经历、对话或精确数据；缺证据时收窄判断、标明未核实或按任务补证。虚构细节可以创造，但须符合已确立的时间、人物知识、规则与因果。涉及当前投稿或平台规则时，按实际需求核实当时官方资料。

### 第6步：交付核对清单

- [ ] 请求范围内的实际正文已完成，未把样章、梗概或场次表冒充全文。
- [ ] 事实、引文、观点或虚构设定没有被无意改动，未决项及其影响已说明。
- [ ] 结构、因果、段落和人物/论证关系能由正文支持。
- [ ] 声音、语域、视角、格式符合目标文体，没有为分数统一成某一种文风。
- [ ] 所报告的检查确实执行，检查范围、方法和assisted/human来源如实记录。
- [ ] 可交付状态与待完成事项分开说明；关键缺口不能被平均分掩盖。

### 第7步：定点修订与停止

优先修影响理解、事实和连续性的问题，再处理有效的语言改进。默认最多两轮有依据的润色；关键事实或结构错误仍须修复或明确其未解决状态。两轮是防止刷分的工作节制，不是合格证明，也不能用来提前终止已授权的必要修复。用户有不同轮次要求时按范围执行；只剩正当文体特征时停止。

## 分层修改：按问题选择检查顺序

长稿可把结构、段落/场景、字句分别检查，以免在即将删改的章节上反复雕句。短稿、局部请求或明显错字可合并处理；没有固定轮数，也没有“混着改等于没改”的规则。

### 结构层：看全局

- 论证稿核问题、结论、证据与限制的关系；MECE只在确实需要互斥分类或穷尽覆盖时使用，不是所有文章和故事的章法。
- 叙事稿核主线/群像关系、信息次序、必要铺垫、人物选择和结局承诺。允许非线性、弱情节、平弧和开放结局，但应说明其在本作品中的功能。
- 给每段、每章或每场写一句“此处做什么”。主题句清楚的论证稿可连读段首句；叙事、对话或诗歌应另写功能摘要，不把没有主题句误判成结构缺洞。
- 结构变动后检查后续事实、时间、伏笔、人物知识和结尾是否受影响；局部修订不擅自扩成整书重写。

### 段落与场景层：看承接

- 核对证据与结论、行动与后果、信息与反应是否连接；必要时补依据、移顺序、改过渡或收窄结论。
- 判断段末总结是在帮助定位、强调关键限制，还是只把上一句重复一次；不按“这说明”之类词语直接删句。
- 场景的功能可以是推进事件、暴露关系、形成压力、建立空间、提供余波或改变读者理解。不要求每场同时完成外部推进和内部改变。

### 字句层：看准确性与节奏

- 按主干、修饰范围和阅读重心拆合句子；具体动词优先于无信息的抽象判断，但不机械替换专业术语。
- 删减以信息和节奏功能为据，保留必要铺垫、复现与留白；没有统一减10%的配额。
- 依内容调整句段速度，保留有效长句、短句、整齐结构与人物语气。不同文风的可选工艺见[style-craft.md](style-craft.md)和[文风光谱](style-spectrum-craft.md)。

### 校对层（需要时单独进行）

检查错字、标点、数字、名字、标题、引文边界和目标格式。按任务可与字句修改合并；有大量结构调整的稿件在定稿后再复核，避免遗漏新引入的问题。

### 换视角与起草心态

把“作者知道什么”和“读者在此刻知道什么”分开检查；可从目标读者的未知处重读。Murray、Lamott、King、Stein等写作经验在旧资料中用于提醒换视角、允许粗稿和分层修订，应视为可选工艺，不能推出人人必须冷却数周、所有好初稿都很差或某句话一定该删。原资料的出处线索见[source-index.md](source-index.md)，未核原文不追加逐字引述。

舍不得删的句子也可能有价值，依据是它在此稿中的作用。卡壳时可先连续写下粗稿（freewriting），之后核实事实和结构；是否边写边改由任务决定。当前起草说明见[单篇写作：写中](writing-workflow.md#写中)，不引用已不存在的“第8条”。长期练习见[long-term-training.md](long-term-training.md)。

## 创作层修改：让故事本身变好

先识别作品的问题层级；如果故事的因果或承诺有缺口，单纯换词不足以修复。长篇深修结合[longform-revision.md](longform-revision.md)，按真实章稿/场稿建立依赖记录，不仅检查台账。

- **整体结构**：目标、处境、关系或核心问题能否贯穿本作品？中段的信息与行动是否积累后果？结局是否处理作品提出的核心承诺？并非所有作品都需要单一强目标或胜利结局。
- **人物与因果**：选择符合此刻知道的信息、欲望和限制吗？能力、资源、伤势和制度能支撑行动结果吗？巧合若参与解决关键问题，前文是否建立了足够依据？
- **场景功能**：这一场提供了什么不可替代或值得保留的经验？安静场、停顿、反复母题、关系展示与环境建立均可能有效。只有实际冗余或破坏节奏时才删合，不因缺一次“反转”就判无效。
- **视角与信息**：谁能看到、知道、误解这件事？揭示顺序对读者是否公平？改场后人物知识、时间、位置和物件有没有断裂？
- **人物弧光**：正弧、负弧、平弧、微变或有意保持均可成立；用选择、关系与后果显示处理方式，不要求结尾必做开篇相反的选择。
- **对白**：它是否表现人物处境、目标、关系、信息或节奏？遮名对读可帮助发现声口混同，但共享职业术语、家人相似用语和有意呼应允许存在，不要求每句都能独立认人。
- **结尾与范围**：伏笔、疑问和读者承诺是否按约定处理？开放设计需要正文依据；未写结尾不能称开放结局，部分场次不能称完整剧本。

**对话复读提示**：问其目的、压力、好奇、关系或气氛作用。这些是观察角度，不是每段对白都要达成的清单；如果全无作用，再考虑删改。

**一卷/一个阶段后的复盘**：记录最影响阅读的少数问题、对应正文位置、改法和后续依赖。字数、删改量、卡壳位置、评阅耗时可选记，不能当文学成绩。下一阶段只选择当前最值得解决的改进，不为凑数量造问题。

## 质量评阅：记录判断与证据

| 维度 | 检查依据 | 可以怎样记录 |
|---|---|---|
| 目标与文体 | 请求范围、读者、媒介、格式、完整正文 | 满足 / 部分满足 / 未核；指出位置与影响 |
| 意义与依据 | 非虚构事实和证据；虚构设定、因果和连续性 | 已核 / 存在问题 / 待核；给原文或材料定位 |
| 阅读与节奏 | 信息是否清楚，铺陈、停顿、重复是否有效 | 改前→改后效果；允许无改善或有得有失 |
| 声音与表现 | 叙述距离、语域、人物声口、情绪和意象选择 | 保留了什么、削弱了什么、是否符合目标 |

不设普遍100分权重或70分回改线；需要量表时先约定适用文体、评分锚点与评阅来源。关键事实、缺章、不可定位正文等问题单独报告，不能由其他项目高分抵消。lint、词频或句长均不能代替这些维度。

## 两个读者：人工反馈的正确用法

有实际读者资源时，可请一位懂题材的人核专业与逻辑，再请目标读者指出难读、误解或脱离体验之处。人物、技术程度和受众不同的任务可选其他组合；这不是每次交付的前置人数要求。

给具体问题，例如“哪一处不知道是谁在说话”“为什么人物会作这个选择”“哪里重复”“你如何理解结尾”。多名读者指出同处是优先核查线索，仍须结合文本和创作目标判断，不机械投票改稿。笼统好评信息有限，也不等于反馈无价值。

模型辅助读稿、匿名交叉模型读稿与真人试读分别标明来源；没有实际读者时，报告已做的文本审读，不虚构人类反馈。

## 不依赖检测工具的替代自查（5 种）

这些方法观察阅读效果，不用于猜作者身份，也没有比检测器“更准”的身份判别承诺。

1. **下一步预期**：停在转折或重要信息前，记录读者已有依据与可能预期。检查后文是否补充有效信息、兑现承诺或建立有根据的意外；可预测可能是说明清楚或类型承诺，不等于写得差。
2. **节奏地图**：任选一段标注句段长短与功能，比较紧张、说明、回味等部分是否有合适速度。只改影响理解或表现的单调；等长句、排比、格律和步骤的整齐有时正是需要的形式，不靠插随机短句改善。
3. **复述测试**：请实际目标读者按适当篇幅复述；没有读者时可做辅助文本复述并注明来源。出现误解后区分是信息缺失、前置知识要求、记忆差异还是作品有意留下的歧义，不一律判成“空”。
4. **声音对照**：若有用户提供且相关的写作样本，比较此稿的语域、距离、判断方式和人物声音。新任务允许新文风；不能因为作者旧稿没用某个词就删它，也不能强行加入“我”。
5. **功能追问（So-What）**：问这段让读者理解、感受、记住或等待什么。说明、过渡、气氛、留白和重复母题都是可能的回答；没有独家事实不等于没有功能。

## 人眼定位法：逐段三问（lint 补不上的那一步）

1. 这一段在本篇做什么？若承担事实或论证任务，依据是否足够；若承担叙事或感受任务，是否与作品有关？
2. 与前后段是什么关系？重复是在强调、对照、呼应、维持理解，还是无意把同一意思又说一次？
3. 删、缩、移或保留各会损失什么？先判断影响，再选最小且有效的修改。

可标出读完难以理解其作用的位置，并记录原因。不是每段都应包含数字、日期、感官或“只有我知道”的细节。

**论证补查**：泛论有没有解释具体条件；例子与结论是否有关；匿名或概括案例是否按文体允许且说明边界；引用承担证据、定义、背景还是争议定位；中立是基于证据不充分还是回避必要判断。引文后不强制加“我赞成/反对”，第三人称和谨慎判断本身不是问题。

## 外部检测与回改优先级

普通编辑不默认送检、上传全文、付费或研究检测论文。用户明确请求相关动作时，按[检测证据说明](detection-principles.md)核对输入范围、服务条件与当时官方说明，再执行授权内操作。工具标注只能是需要复核的线索，不能当成空洞、抄袭、作者身份或文学质量的证明。

回改按作品影响排序：事实/设定错误与缺失正文 → 因果和结构 → 信息承接与声音 → 有收益的字句润色。外部报告的红色密度不替代这一顺序；保留有功能的标记并解释判断，不为清零无限重写。

常见的过度修改包括：无上下文的整篇同义词替换、为阈值插短句、为个人感造经历、靠错字乱标点显得随意，以及每轮全量重写导致事实/声音漂移。比较原稿与改稿，保存必要的版本与改动依据；需要整体重写时仍应基于明确结构问题和授权范围。

## 被要求“证明是你自己写的”时

如实说明实际写作和工具使用过程，保留可用的草稿、版本历史、原始数据/访谈笔记、提纲演化及往来记录。面谈解释思路可以补充材料，但没有单一证据或口头表现能够绝对证明作者身份。不得补造时间戳、笔记或人类评阅记录。

需要回应机构或平台时，依其当时的实际程序提供相关材料；不承诺检测分数足以证明或推翻作者身份。检测局限的证据须按[detection-principles.md](detection-principles.md)区分来源与适用范围，不照搬未经核实的高校名单、价格或处罚结论。

## 25 项功能性自查清单（按需）

沿用旧手册的六类观察位置，改为“什么影响阅读、怎样检查、何时保留”。没有命中数量、词表阈值、句长方差门槛或第一人称配额。按当前问题挑选，不要求每份文本检查25项，也不将命中视为AI身份特征。

### A. 结构类（5 项）

| 项 | 功能性问题与检查动作 | 保留边界 |
|---|---|---|
| A1 段落长度 | 段落体量是否与信息和表现任务匹配；找读者受阻的位置 | 平行条目、整齐段落和短章均可有意设计 |
| A2 段首方式 | 开头是否帮助进入内容；主题句是否只是空判断 | 学术、技术和说明文可连续使用主题句 |
| A3 开头结尾 | 开头建立的期待与结尾处理是否一致、具体 | 必要概括、格式化收束和开放余味允许存在 |
| A4 段内组织 | 概括、展开与小结是否分别提供价值 | 总分总可以服务定位与记忆，不为变化而变化 |
| A5 主次安排 | 重要关系是否得到足够篇幅和读者注意 | 均匀群像、克制叙述和渐进铺垫可符合目标 |

### B. 句式类（5 项）

| 项 | 功能性问题与检查动作 | 保留边界 |
|---|---|---|
| B1 句段速度 | 长短是否适合内容、语气和阅读负担 | 等长不判AI，不强插短句提高离散度 |
| B2 复合句 | 主干、并列和转折关系是否清楚 | 对仗、法律条件和技术限定可保持完整 |
| B3 重音与停顿 | 关键判断、动作或情绪是否获得合适停顿 | 可用信息顺序、标点或长句完成，不强求独词句 |
| B4 插入与标点 | 插入语是否遮住主干，标点是否准确 | 破折号、分号和括号按意义与文体保留 |
| B5 问句 | 设问、反问或对话提问是否有具体作用 | 真疑问、修辞提问与悬念均可有效，不按数量删 |

### C. 用词类（4 项）

| 项 | 功能性问题与检查动作 | 保留边界 |
|---|---|---|
| C1 通用表达 | 在上下文中是否准确或只是空过渡；可检索词语定位 | “闭环”“维度”等术语及必要路标不按词表禁用 |
| C2 修饰强度 | 程度词是否有依据，修辞是否符合声音 | 没有数据就不能编百分比；情感表达不都需量化 |
| C3 领域措辞 | 指称是否准确且适合受众，是否漏必要名称或限定 | 通俗文不强塞行话；不可为具体而造公司、版本和出处 |
| C4 重复用词 | 是精确指称、人物声音、母题，还是空泛动词循环 | 不为提高TTR替换固定术语；统计值不能代替语义判断 |

### D. 内容类（4 项）

| 项 | 功能性问题与检查动作 | 保留边界 |
|---|---|---|
| D1 细节与例子 | 材料能否支持此处判断或体验，例子是否相关 | 非虚构细节须真实有据，虚构细节须自洽；可按规范匿名 |
| D2 泛化判断 | 是否解释适用条件、作用机制或作品中的具体意义 | 过渡、必要共识和题旨复现不因抽象就删除 |
| D3 作者位置 | 立场、叙述距离与已知边界是否清楚 | 无需第一人称；非虚构不得凭空增加经历 |
| D4 引用功能 | 是否忠实溯源并与定义、背景或论证有关 | 不要求每条引文后表态，不以对抗性评论替代证据 |

### E. 逻辑类（4 项）

| 项 | 功能性问题与检查动作 | 保留边界 |
|---|---|---|
| E1 过渡 | 实际因果、并列、转折成立吗，路标是否准确 | 程序步骤和专业论证可需要明确连接词 |
| E2 详略与留白 | 什么必须讲清，什么可由目标读者推知 | 不为“人味”制造逻辑断裂；保留必要论证步骤 |
| E3 条件与判断 | 结论强弱是否匹配证据，冲突观点是否交代 | 中立与两面讨论可正确，不强行选边或制造矛盾 |
| E4 总结与复现 | 重述是否帮助理解、强调限制或形成呼应 | 总结有信息功能即保留，无效复述才删缩 |

### F. 情感类（3 项）

| 项 | 功能性问题与检查动作 | 保留边界 |
|---|---|---|
| F1 表达方式 | 直陈、动作、意象或对白能否支持目标情感 | 直抒、华丽和克制均可成立，不统一成冷笔 |
| F2 情绪走势 | 语调是否与事件、论证及人物处境相称 | 平静公文、冷幽默、持续压抑等允许稳定语调 |
| F3 立场与声音 | 是否无意改了作者真实判断或人物态度 | 不强加反叛、不圆满或私密感；有意含混须有作品依据 |

使用时保留少量有正文定位的发现，记录修改作用与副作用；事实、结构、连续性和有效表现优先于特征统计。完成范围按项目契约和实际正文核实，清单数量不是质量证明。
