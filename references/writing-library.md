# 写作资料库：规范、书目与工具（v0.60）

本文件解决“写的时候该查什么”。只登记**能回溯到出处**的资料；查不到出处的经验说法不进来。

核查日期：2026-11-12。每条标注核查级别：

- **A**：本轮已打开页面，确认标题/标准号/状态；
- **B**：页面可访问，但内容未逐条核对；
- **C**：只到书目或二手信息，未核版本与正文。

---

## 1. 语言规范（硬约束，优先于任何文风建议）

这三项是现行国家标准，写公文、教材、出版物、正式文书时应先满足它们，再谈“人味”。

| 标准号 | 名称 | 状态 | 管什么 | 核查 |
|---|---|---|---|---|
| GB/T 15834-2011 | 标点符号用法 | 现行 | 17 种标点符号的用法、位置、连用与套用 | A：https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=22EA6D162E4110E752259661E1A0D0A8 |
| GB/T 15835-2011 | 出版物上数字用法 | 现行 | 阿拉伯数字与汉字数字的选择、概数、日期、计量 | A：https://openstd.samr.gov.cn/bzgk/std/std_list?p.p1=0&p.p2=GB%2FT%2015835-2011&p.p90=circulation_date&p.p91=desc |
| GB/T 9704-2012 | 党政机关公文格式 | 现行 | 公文版式、要素、字体字号、行距 | A：https://openstd.samr.gov.cn/bzgk/std/std_list?p.p1=0&p.p2=GB%2FT%209704-2012&p.p90=circulation_date&p.p91=desc |

用法提醒：

- 三项标准只给“格式与用法”，不给“文风”。把公文写得像公文，和写得有人味，并不冲突；先合规，再谈可读性。
- 标准全文在“国家标准全文公开系统”可在线阅读；**不要凭记忆复述条文**，尤其标点连用、数字分节、公文层级序号。
- 平台（公众号、起点、晋江、期刊）另有自己的排版与投稿要求，且会变；以投稿时的官方页面为准，本文件不复制过期规则。

## 2. 语法与修辞参考书目（商业出版物，仅列书目）

这些书没有可公开引用的全文链接，本技能**不复制、不分发**，只作为“遇到具体语法争议时该翻哪本”的指路。

| 书 | 适合查什么 | 核查 |
|---|---|---|
| 朱德熙《语法讲义》，商务印书馆 | 现代汉语句法成分、句型、歧义 | C：仅书目，未核当前版本 |
| 吕叔湘、朱德熙《语法修辞讲话》 | 常见语法错误、修辞毛病、修改示例 | C |
| 王力《中国现代语法》 | 汉语语法体系、句式演变 | C |
| 陈望道《修辞学发凡》 | 修辞格分类、消极修辞与积极修辞 | C |

使用原则：书里的例句属于历史语料，**不要照抄例句**；判断当前用法时，以现行规范和具体语境为准。

## 3. 公版写作论（可读原文）

| 篇目 | 讲什么 | 入口 | 核查 |
|---|---|---|---|
| 鲁迅《作文秘诀》 | 反对“作文教程”式的花架子 | 收入《鲁迅全集》；维基文库有转录页 | C：本轮 Wikimedia 域名访问超时，未核正文 |
| 鲁迅《答北斗杂志社问》 | 八条写作主张：不硬造、不生造、看外国书等 | 同上 | C |
| William Strunk, *The Elements of Style*（1918） | 英文写作的简洁、主谓一致、并列结构 | https://www.gutenberg.org/ebooks/37134 | A：页面标题与版本已核 |
| George Orwell, *Politics and the English Language*（1946） | 反对陈词、被动、空洞套话 | https://orwellfoundation.com/the-orwell-foundation/orwell/essays-and-other-works/politics-and-the-english-language/ | A：页面可访问 |
| Purdue OWL | 学术写作、引用格式、段落组织 | https://owl.purdue.edu/owl/general_writing/index.html | A：页面可访问 |
| Writing Commons | 开放写作教材：结构、修辞、编辑 | https://writingcommons.org/ | B：页面可访问，许可未核 |

Strunk 的价值在于“删冗余”，不在“句句短”。把它当成删词清单会写出电报体；Orwell 的六条规则最后一条是“宁可打破任何一条，也不说蠢话”，这一条比前五条更重要。

## 6. 语料库

写作资料之外，真正能校准“像不像人”的是语料。本项目随包语料、既有冻结语料与未随包数据集的许可状态，统一登记在 [语料清单](corpus-manifest.md)。要点：

- HC3-Chinese（CC BY-SA 4.0）可随包，已随包；
- C-ReD 上游未声明许可，不随包；
- 公版民国文本可随包，但存在版本与节选问题；
- 网文数据集卡片写 Apache-2.0，正文却是受版权保护的小说原文，不能据此再分发。

## 7. 按任务查什么

| 任务 | 先查 | 再查 |
|---|---|---|
| 公文、通知、报告 | GB/T 9704-2012 → GB/T 15834-2011 → GB/T 15835-2011 | 本单位现行行文规范 |
| 学术论文、学位论文 | 目标刊/本校稿约 → Purdue OWL（英文） | 学科惯例、引用格式 |
| 标点拿不准 | GB/T 15834-2011 | 同体裁权威样本 |
| 数字写法拿不准 | GB/T 15835-2011 | 目标平台规范 |
| 句子别扭、成分残缺 | 《语法讲义》相关章节（书目） | 本项目 `han-prose-grammar.md` |
| 修辞过度、套话多 | 陈望道（书目）+ 本项目 `rhetoric-craft.md` | `deai-techniques.md` |
| 英文写作、翻译腔 | Strunk、Orwell、Purdue OWL | 本项目 `sentence-discipline.md` |
| 想要“人味”参考 | 公版散文、小说（见语料清单） | 目标文体的真实样本，不用 AI 生成样本当范文 |

## 8. 未核实与不能引用

以下资料常被引用，但本轮**没有**核到可回指的权威出处，因此不进入建议清单：

- “中文平均句长 17 字”“一段不超过 5 行”之类数字；
- 各种“AI 高频词 Top 100”榜单（多无标注语料与统计口径）；
- 平台“限流词”“敏感词”清单（各平台规则不同且变动频繁）；
- 教辅类“作文模板评分标准”。

需要用时，先找到原始发布方与统计口径，再决定是否引用。
