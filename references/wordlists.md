# 常见模板表达与检查词表（中英文）

> **使用原则**：这些表达不是错误或作者身份的证据。密集或重复出现时，可检查其是否空泛、累赘或与语体不合；承担术语、衔接、声音或有意重复功能时保留。
> 自查方式：搜索只帮助定位，不设“出现几次就处理”的阈值；逐处说明问题后再决定保留、压缩或改写。
> 脚本 `ai_smell_lint.py` 可提示候选位置；计数不证明作者身份，也不能替代上下文判断。

## 特别说明：破折号（em dash）

破折号被网友戏称为 "ChatGPT hyphen"，很多读者一看到满篇破折号就本能怀疑 AI。

但**研究层面它不是可靠判定证据**——很多优秀的人类写作者本来就爱用破折号。

处理原则：**如果你的读者群对它敏感，就控制密度；不要把它妖魔化**，更不要为了"去 AI 味"把正常的破折号全改成逗号（那会毁掉节奏）。

## 不得单独当作 AI 味证据的特征（反黑名单）

这一节的存在理由是先量过的，不是立场声明：

- **本轮自测**：`tests/corpus_classic/` 的 11 篇真人作品（鲁迅散文·杂文·演讲、朱自清散文、清帝逊位诏书）在 `general` 档下有 **5 篇命中 >0**（4／4／6／8／9 分），其余 6 篇 0 分；而按功能改选档位后，闻一多《最后一次讲演》在 `speech` 档 **0 分**、《狂人日记》在 `fiction` 档 **0 分**。**同一篇人写的文本，命中数由调用者选的档决定。**
- **外部公开校准**：一个同类项目在 35,158 条学术摘要的标注语料上报告，严格模式的硬禁用词在 **35.9% 的人类文本中依然命中**，机器文本为 26.1–35.8%——在该领域**基本分不出作者**；加上体裁修正后人类误触降到 4.2%。另一项目记录其改写稿送第三方检测后仍全部判为 AI 或混合，被认作人写的比例平均约 3%。
- **社区清单的自我修正**：Wikipedia:Signs of AI writing 已把「Overuse of em dashes」移入 **Historical indicators** 并标出年份区间（厂商侧压制后，"不敢用某种标点"反而成了新痕迹），同时明写检测工具「有非平凡的错误率」。该页另有一节专门列出**无效指标**，本轮只确认其存在，未读到条目正文，**不在此复述它的清单**。

因此下列特征**不得单独**当作"像机器写的"的证据，也不得据此改稿或指控作者：

| 特征 | 为什么不是证据 |
|---|---|
| 语法完美、没有错字与病句 | 校对过的稿子、谨慎的作者都会这样；把它当缺陷等于奖励粗糙 |
| 正式或学术文风、术语密集 | 语域由场合与读者决定，[genre-router.md](genre-router.md) 已列公文/法律/学术的平行结构为功能要求 |
| 语域混用（书面夹口语、专业夹日常） | 公共写作、科普、演讲常见；混用本身不定错 |
| 孤立的"首先／然而／综上所述"等过渡词 | 单个过渡词不承载任何作者信息，成簇且无语义作用才值得查（见本页使用原则） |
| 平实质朴、不出彩的文风 | 平淡是风格选项，不是机器指纹 |
| **非母语写作特征、方言与双语混用** | 把合格的双语表达当缺陷会系统性误伤一类作者；本技能禁止以"更像母语者"为名抹平这些特征 |
| 引用少、无外链、缺少个人轶事 | 这是内容与体例选择，不是身份证据；**也不得反过来为了"像人"补编轶事** |
| **命中数本身**（0 或 100） | 脚本只统计静态线索；跨档位、跨版本数字都不可比 |

正确的用法仍然是本页开头那条：**先找具体的文本问题**（空泛、重复、语域不合、事实无依据），词表和命中只负责**定位**，不负责定罪。

## 替换方向（保住事实、语义和语体）

### 按实际问题选择改法
1. **补证据**：抽象评价需要依据时，只补原稿已有或核验过的具体事实；没有材料就标待补，不新增经历、数值或来源。
2. **解释所指**：读者不熟悉术语时用易懂表达；专业概念、限定条件和正式语气需要时保留。
3. **调整措辞**：同义替换可以解决局部歧义或重复，但必须保持原意；不能保证改变检测结果，也不必为检测而改。

| 待检查的表述 | 可能仍未解决问题的换词 | 有证据时的具体化方向 |
|---|---|---|
| 取得了显著的成效 | 获得了突出的成果 | `[待补：真实结果与比较口径]`；证据不足时不增强“显著”判断 |
| 存在诸多问题 | 面临不少挑战 | 列出材料中确有的问题；不创造窗口数、队伍长度等场景 |
| 进行了深入的分析 | 开展了透彻的剖析 | 说明已记录的分析对象、方法和发现；不编造反复查看次数 |
| 极大提升了用户体验 | 大幅优化了用户感受 | `[待补：真实体验指标、变化幅度、样本与来源]`；没有数值时不补数值 |

### 英文表达的简化候选（核对语义和语域后使用）
| 原表达 | 可考虑的表达 |
|---|---|
| utilize | use |
| leverage | use / draw on |
| delve into | look at |
| navigate the complexities of | deal with the hard parts |
| a wide range of | 直接列出具体几项 |
| furthermore / moreover | also / and |
| in order to | to |
| it is important to note that | （删掉，直接说事） |
| due to the fact that | because |
