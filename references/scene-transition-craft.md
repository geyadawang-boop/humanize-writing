# 场景转场与切镜

> 属于[长篇小说创作参考](novel-craft.md)的分册。按问题进入本页，不必回读整包。

本节管**转场**：两场戏之间怎么接——时间跳多少、空间换多远、镜头怎么切。适用长篇 / 连载。转场是叙事的关节，不是铰链上的木屑。

## 转场六法

1. **时间转场：标"过了多久"不如标"这多久改变了什么"**。"三个月后"只是交代经过量，读者真正想知道的是这三个月在故事上起了什么作用——前一场吵架的两人，"三天后"是谁先低头、关系变质了没有。
   - 轻量跳过：空行 / 分隔符（***）＋一句 "later…" "the following week…"。
   - 重量跳过：用一段"概述性总结"（summary）交代发生了什么、改变了什么，再进下一场戏。
   - 详略原则：时间跨度越大，越要概括；时间越逼近高潮，越要逐拍细写。
2. **空间转场：按理解需要定位**。时间、地点、视角人物可帮助读者定位，已能从上下文理解时不必重报。结尾与下一场开头可选动作、观察、概述或停顿；路途也可承载声音、氛围或人物变化，不以锚点数量或是否赶路决定删留。
3. **平行剪辑（parallel editing / cross-cutting）**：两条线同时进行、交叉出现，靠频率制造悬念。适用：A 线在赶去救 B，B 线正在遇险；两线交叉频率随危机升级而加密——开始慢、结尾快。前提：先给每条线一个清晰目标，读者才知道在等什么。小说里用"章节内交叉小节"或"视角切换"实现，不必写 CUT TO。
4. **蒙太奇（montage）**：把若干短镜头组接，用来压缩时间或积累情绪。经典用途：训练蒙太奇（学技能的过程）、恋爱蒙太奇（几个月感情在几段画面里长大）、成长蒙太奇。节奏：每个短镜头只给一个意象 / 动作，靠"累积效应"产生单场戏给不了的效果；结尾用一个长镜头 / 慢下来的画面收住。小说可借鉴：用 3–7 个不完整句的短段，每个一行，快速切意象。
5. **硬切 vs 软切**：**硬切（cut）**——上一场结束于变化点，空行，下一场直接在动作中开场。最现代、最快，信任读者能补出中间的空白；从"摔门"直接切到"律师事务所"，力量感来自落差。**软切（bridge / splice）**——用一段概述性过渡或道具 / 意象 / 视线衔接两场，流畅感来自"承上启下"。各自适用：无信息量的间隔→硬切；间隔本身有戏、需要对比或伏笔→软切。
6. **转场本身就是叙事**：好的转场不只是换景，可以同时承担——时间压缩（蒙太奇 / 概述）、情绪对比（喜庆接噩耗、喧闹接寂静）、伏笔埋设（上一场看见的物件，下一场回收）、视角切换（借角色目光把镜头递给下一个人）、悬念制造（平行剪辑让读者知道得比角色多）。

## 转场公式与自检

**三种"接缝"的选用**：
```
硬切 cut   —— 间隔无信息量，或跳跃本身有表达力
概述 bridge—— 间隔需要交代，且交代本身有戏
衔接 splice—— 用道具/意象/视线把两场缝成一个动作
```

**转场自检清单**：
1. 上一场的结束位置是否支持其目的与下场衔接？不固定在情绪峰值之后。
2. 下一场所需的时间、地点或视角信息是否可理解？不设前三行交代完的要求。
3. 有没有写"路上 / 火车上 / 坐车到……"这种可被读者自行脑补的物流？
4. 这次时间跳跃是否清楚，省略是否符合本作节奏？间隔中没有重大改变也可以跳过。
5. 平行剪辑的两条线，各自的目标读者清楚吗？
6. 蒙太奇的数量、节奏与结尾是否产生所需效果？不设七个镜头的上限或必须慢收的要求。
7. 这个转场是否有效完成换景或其他所需作用？只承担清楚的换景也可以成立。

**速查表**：

| 转场方式 | 做什么 | 适用 | 风险 |
|---|---|---|---|
| 空行/***＋一句过渡 | 标时间跳跃 | 轻量跳过、日常推进 | 滥用成"然后体" |
| 概述段 | 交代一段时间的变化 | 时间跨度大、阶段总结 | 写成流水账 |
| 硬切 | 直接换景、在动作中开 | 间隔无信息量、要力量感 | 跳太猛读者迷路 |
| 道具 / 意象衔接 | 上一物接下一景 | 埋伏笔、情绪呼应 | 硬凑象征 |
| 视线转场 | 借 A 的目光引出 B | 自然引入新人物 / 新场景 | 每次都用则俗套 |
| 平行交叉 | 两线交替 | 营救 / 倒计时 / 双线对比 | 目标不清则混乱 |
| 蒙太奇短镜头 | 组接压缩时间 | 训练 / 恋爱 / 成长过程 | 镜头重复且没有时间、状态或认识变化 |
| 信息转场 | 同一句话换个人反应 | 制造对比、多视角 | 信息重复不推进 |

## 转场正反例五组

**组 1（"三个月后"水过渡→标出时间带来的变化）**：反——"三个月后，他回到了那座城市。"三个月干了什么、人变了什么，一概不知，纯跳帧。正——先给锚点再给变化："三年没回县城，火车站的拉面摊换成了连锁奶茶店；他口袋里那张欠条还在。"时间跨度用两个具体对照物落地。出处：日本小说写作教程（时间转场要示"今の意味"，不是経過量）。

**组 2（"他坐车到了……"式水字数→硬切到动作中）**：反——"他买了票，上了火车，坐了六个小时，下车打车到学校门口，走进教学楼。"全程无戏。正——在情绪点后硬切：上一场他被退婚摔门而出，空行，下一场直接"教务处的日光灯白得刺眼，他把那份退学申请推过桌面"。中间六小时由读者脑补。出处：Writory（cut ends on the change, opens in motion）、NovelOS（skip the logistics）。

**组 3（两张皮平行剪辑→交叉频率随悬念加密）**：反——两条线各写一章再换，读者早忘了另一线在干嘛，平行剪辑毫无张力。正——营救戏先长段交代 A 在布置，再切 B 的危险；越来越短——A 的脚步声、B 的呼吸、门把转动……交叉频率随倒计时加快。出处：First Draft Pro（intercutting heightens tension）、中国青年作家报《把蒙太奇带入你的写作》。

**组 4（逐拍写训练→蒙太奇短镜头组接）**：反——把"他练了一年剑"拆成三百章日常，拖沓失焦。一种处理——选取有时间或状态变化的片段组接："清晨第一百次挥剑，木剑裂开。雪落在剑刃上。第三百次，他能听见风从哪个方向来。"镜头数、行数和句长按本段作用确定；逐拍短句和连贯概述都可试读，避免同一状态的无用重复。出处：EnsembleWriter（montage condenses time）、Fiveable（training montage）。

**组 5（硬转场景→道具 / 意象 / 视线承担叙事）**：反——"画面一转，来到了反派的书房。"正——上一场女主被害入狱、吃尽苦头；下一场不切人，先切一碗鱼——反派在吃鱼，女主是砧板上的鱼肉。用意象做软切，同时埋处境隐喻。或用视线转场：B 走出房门迎面看见 C，借 B 的目光把镜头递给 C。出处：话本小说《写小说的转场技巧》、起点作家助手。

## 转场书目与创作谈

- 中文：中国青年作家报《把蒙太奇带入你的写作》、晋江文学城论坛《10 种转场的方法》、话本小说《写小说的转场技巧》、起点作家助手《角色目光转场》。
- 英文：Writory（三种接缝词条）、Caro Clarke《Transitions: getting your story through time and space》、First Draft Pro、EnsembleWriter、NovelOS、Fiveable。
- 理论迁移：电影蒙太奇理论（爱森斯坦）在小说中的对应写法——训练蒙太奇、营救交叉剪辑。
- 作者谈要点：转场不是铰链上的木屑，而是叙事本身（Caro Clarke：splices are intrinsic parts of the narrative, not furniture）；能省则省，能对比则对比，能埋伏笔则埋伏笔。
