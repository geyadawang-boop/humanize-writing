# 汉语行文决断（宾主 · 信息流 · 连接 · 语序 · 收束 · 节奏）

句子读着别扭、重心落错、修饰语堆在名词前、连词位置怪、段末收不住时读本篇。它只补**汉语语法层面**的约束：比喻与象征见 [rhetoric-craft.md](rhetoric-craft.md)，衔接、主述位、段间缝合与详略见 [prose-flow-craft.md](prose-flow-craft.md)，改稿时原意是否走样见 [sentence-discipline.md](sentence-discipline.md)，工整化与拉踩见 [argument-and-rhythm.md](argument-and-rhythm.md)。

> 本篇蒸馏自陈望道《修辞学发凡》、朱德熙《语法讲义》、赵元任《汉语口语语法》的落笔规则（原整理见 linguistic-prose-gates 原理库）。只保留可执行的判断与动作；原库“每千字几次”“超过两成”一类阈值一律降为抽查提示，**不作验收门槛，不据单条计数判稿**。单轴合格不等于跨轴合格：一篇稿可以句长合格而分句过碎，也可以清单整齐而段落无重心；改稿按意义与声音裁决。

## 一、先定重心：这句话要读者记住哪个成分

1. **宾主由意思的轻重定，不由句子的工拙定。** 下笔前先答：这句写出去，读者该记住哪个人、哪件物、哪个动作？把那个成分放主语位或句末重位，其余降为修饰。答不出，说明这句本来没有重点，先删。
   - 检验：把句子抽成“谁—做什么—对谁”，看主干是否正是你要人记住的那件事。
   - 反例：同一件“奔马践犬”，六种句法都成立，差别只在着眼在马、在犬、在道；反复润色用词而重心没动，句子依旧别扭。

2. **改不动词就改重心。** 遇到“怎么写都不顺”，先换主语或换句末成分；还不行，说明这句在段中的位置错了，不是词的问题。

3. **删成分要做错挂测试。** 删主语、删动词、删限定词后重读：不加这一成分，读者会不会把它安到另一个对象身上？会，就必须补回。“母，韩女也，滑稽多智”删掉主语，句法没坏，意思却变成母亲滑稽。

4. **重复要看有没有换来新东西。** 同一词连用，每用一次都推进一层（递进、转折、程度加深）就是节奏；第二处与第一处相同，就是空耗。

5. **“是……的”是现成的焦点槽。** 要标出时间、地点、方式、对象，把它框进“是……的”之间，一句只用一次；连用两次以上，等于每句都宣告重点。不要把“关键在于”“尤其是”当焦点槽，那只是宣告“我要强调”。

## 二、修饰语怎么排：信息流

1. **定语次序有结构，不只是语感。** 带“的”的定语在不带“的”的定语之前（“瓷的小茶壶”，不是“小瓷的茶壶”）；都不带“的”时，次序是领属 → 数量 → 形容词 → 名词（“他那件新羊皮大衣”）。数量词与领属定语可以前置，是例外。

2. **“的”的隐现看能不能进词典。** 现成类别不带（“蛋白质结构”“语法单位”“经济政策”），临时限定带（“昨天的报”“他的眼镜”）。把术语写成“细胞的结构”“数据的库”，是把术语降成描述。

3. **修饰超过两层，把带动作性的那层改成谓语。** “用于……的”“基于……的”本来就是谓词结构，还原成谓语句最省力：“一个基于深度学习的用于蛋白质结构预测的模型”改成“用深度学习预测蛋白质结构的模型”。数名词前的修饰层数，三层以上就查。

4. **状语位置分叙事与评论。** 放句首，它笼罩全句，读者先得态度后得事实；放主谓之间，事实先立住，再补态度。叙事用后者，评论用前者。全篇“显然”“事实上”“值得注意的是”开头，读者读到的全是姿态。

5. **双音节形容词修饰名词，默认带“的”。** 只有已凝固成术语（“主要矛盾”“高级干部”）或换成名词性定语（“高效率”）才省。不要靠删“的”求简洁。

6. **抽象双音节形容词直接做状语会失血。** “深入研究”“全面提升”“有效解决”语法上可以，但抽象、无画面；想让动作带样态，用叠词或“……地”。

7. **区分性修饰语紧挨名词，描写性修饰语放远或改谓语。** “一位来自南方、性格温和、擅长书法的年轻教师”三层全是描写，却全挤在区分位，读者找不到“是哪一个”。改成“那位年轻教师来自南方，性格温和，写得一手好字”。

8. **“把”字句的宾语必须已经出场。** 把宾语提前等于宣布“读者已经知道它”；首次出现就用“把”，句子会悬空。“首先把数据进行清洗”改“先清洗数据”。

## 三、连词的位置

1. **两组连词不能互换位置。** 前分句组（虽然、如果、即使、既然、不但、无论、不管、尽管等）只能出现在前一分句；后分句组（但是、可是、所以、然而、而且、并且、否则、何况等）只能出现在后一分句。前组出现在后分句是临时追加（“我明天一定来，要是下雨的话”），后组出现在句首是跨句承接；除此两种，位置错即语法不合。

2. **后组连词开句，前文必须有它的对立项。** 每个句首“但是”“所以”，回看前一段找被转折或推出的内容；找不到就是空转，读者会回头找那个不存在的前提。

3. **前组连词随主语同异换位。** 主语相同放谓语前（“他虽然没去，可是什么都知道”）；主语不同放主语前（“虽然他没去，可是我知道”）。换位改变读感，选与句群话题一致的那个。

4. **成对结构先定辖域。** “与其……不如……”“不但……连……也……”“除非……”位置一挪，被比较或否定的范围就变。先定范围，再把连词放在范围边界上。

5. **分句不是句子。** 三个以上分句都能独立成句、加句号也通，就是“伪长句”：形式是复句，实质是三个短句拴在同一个标点上。合格的分句离开主句应当不知所云。

## 四、语序

1. **调序前先问原序在承担什么。** 汉语没有形态标记，语序同时承担话题、焦点与疑问。“这本书我看过”重点是书，“我看过这本书”重点是我；只想“调顺”就动手，重点会丢。

2. **倒装的后置部分必须轻。** 后置部分要短、可推知、不必用力；又长又重就不是倒装，是句子写散了。“一份报告交上来了，关于去年全年的经营情况的”是反例。

3. **受事可以直接作主语，不必求“被”。** “碗打碎了”比“碗被打破了”干净，“问题解决了”比“问题被解决了”自然。只有需要标明施事、或施事不明会造成误解时才用“被”。通篇“被提出、被实现、被解决”是翻译腔的典型。

4. **短句不必补主语，长句未必完整。** 判据只有一个：补出这个成分以后，句子是否更合语法且更清楚。补不出，就是完整句；补了更啰嗦，说明原文已足。

## 五、收束：末句把读者留在哪一边

1. **末句的分量要与全文实际分量相符。** 通读后只看最后两句：牵强收场（把小事说成大势）与轻描淡写（把大势说成小事）都是失衡。前面讲一个具体技术细节，末句抬到“开启新篇章”，读者的感受是虚。

2. **陈述事实的句子不加语气词。** “啊/呢/吧/嘛/呗/啦”只改温度，不加信息；论述、报告、说明全篇不加，口语叙述一段最多一处。口语的自然来自句式与词序，不来自语气词堆叠。

3. **“吗”是不知而问，“吧”是已知求证实。** 真要问用“吗”；引导读者确认自己的判断用“吧”，但那是压回应的句式，一段一次即止。满篇“是不是可以这样理解？”是施压，不是商量。

4. **断点只落在三类位置。** 主语之后、连词之后、并列项之间。不要在副词、介词、助词之后断，不要在动宾之间断。“在这个意义上，我们／需要重新／考虑这个／问题”每一处都断错，读起来像翻译软件。

5. **段末要“举要”。** 每段把最有分量的一句挪到末位；挪不动（因为末句是过渡），说明这段的重心在段间，合并到下一段。段末全是“接下来我们看”“由此可见”，读者记住的是一串路标。

## 六、节奏：整齐与参差

1. **排比最多三项，第四项换句式。** 整段已有两组排比，第三组改散文句。宁可少排比，不可让读者开始数拍子。

2. **错综四法按层查。** 抽换词面（邻近对应位置不重复同一个词）→ 交蹉语次（该错开而完全一致的结构）→ 伸缩文身（连续四句以上长度接近）→ 变化句式（整段全是陈述）。四层可单用，不必全上。

3. **顶真只在推演关系上用。** 后一句要由前一句的结尾真正推出；“效率意味着……这意味着……”只是话题链，不是顶真，读起来是套娃。

4. **拆掉清单必须回填长句。** 删一处冒号分号清单，就在同段造一处四十字以上、含虚词承接、不含冒号分号的复句；只拆不补，只是把“假长句”换成“真碎句”，节奏问题换了一边。

## 七、怎么用这篇

1. 依次查：重心 → 修饰语 → 连接 → 语序 → 收束 → 节奏。一次只改一类，改完读出声；六类一起动，改完分不清收益来自哪一步。
2. 每条都先问“这里是否承担意义”：语序可能承担焦点，重复可能承担节奏，短句可能承担停顿。承担了就保留。
3. 不按计数验收。本篇不给配额，也不与 `ai_smell_lint.py` 的零权重观察项互相证明；lint 报警只指出位置，是否改按本页判断。
4. 与 [prose-flow-craft.md](prose-flow-craft.md) 的分工：那边管衔接五法、主述位、段间缝合与详略；本篇管**汉语语法**层面的词序、虚词与断句。两篇同时命中时，先按本篇修语法，再按那边修段流。
