# 感情线写作

> 属于[长篇小说创作参考](novel-craft.md)的分册。按问题进入本页，不必回读整包。

本节管**感情线**：主线与感情线怎么咬合、CP 感从哪来、暧昧期怎么推拉、甜虐怎么配比。适用长篇 / 言情 / 网文。对话怎么写在 dialogue-craft.md；本节管关系曲线本身。

## 感情线七法

1. **双线关系的选择**：情节与感情线可以相互推动，也可平行、交错或让感情成为主线。检查它们的比例与连接是否符合本作目的；关系变化可以来自外部事件，也可来自日常相处和内心认识，不要求每次升温推动一个主线决策。
2. **阻力差是一种张力工具**：可比较想靠近的理由与不能靠近的条件；这不是 chemistry 的唯一公式。匹配、欣赏、相处趣味与稳定的共同生活也能形成吸引力，不为填公式强加分离。
   - 拉力（pull）：生理吸引、共同目标、真心喜欢与尊重、相处有趣、彼此懂得。
   - 推力（push）：外部阻碍（责任 / 危险 / 门第 / 立场）、内部恐惧（旧伤 / 不配得感）、误会、价值观分歧。
3. **暧昧期推拉节奏（可选）**：可试“靠近→退开→再靠近”的波动，前提是退让符合人物处境。也可持续靠近、停留或直接表达，不规定每轮风险递增，也不为保持波动在甜蜜后强加伤害。
4. **肢体距离的表达选项**：距离、动作、潜台词与直接告白都可表现关系。需要犹疑时可写想碰又收回；需要坦诚时可直接说“我喜欢你”。不规定固定阶梯、甜后立刻收回，也不把身体表达排在语言之上。
5. **一种关系推进样例**（可省略、重排或另选节点，不要求误会与表白）：初遇（带反差 / 误解）→破冰（被迫共处，发现对方不讨厌）→误会（信息不对称制造的裂痕）→心动确认（自己骗不过自己的瞬间）→表白 / 关系转折。
6. **表白戏不是终点，是新起点**。常见写法：直接告白；误会错过（话到嘴边被打断）；事件触发（生死关头 / 危机中脱口而出）；酒后失态；借第三方 / 信物替代语言。关系确立后，可探索共同生活、新的理解或仍存在的矛盾，也可就此收束；不为避免平稳而强加恐惧或利益冲突。
7. **甜虐安排**：若作品选择甜虐交替，可检查起伏与人物处境是否相容；全程甜、长期疏离或平静相处同样可以成立，不替所有读者预设必须付出代价的偏好。

## 感情线公式与自检

**感情线结构公式**（晋江写作日志，作者自陈）：
```
小磕点（上扬）→ 虐点（下压）→ 大磕点（再上扬）→ 虐点（再下压）→ 和解（平滑过渡）→ 更大的磕点
```
关键节点：第一次亲密接触 / 第一次误会 / 第一次分离——这三"第一次"是读者看文的回报点。

**推拉四问**（写每场暧昧戏前问自己）：
1. 这场戏里，谁更想要靠近？为什么？
2. 谁先退？为什么退？退的理由是否具体、可追溯？
3. 肢体距离比上一场近了还是远了？近 / 远了多少（一寸还是一步）？
4. 这场戏结束时，读者的心跳是更高、更低，还是悬空？

**反工业糖精检查项**：
1. 亲密是否跳过了"为什么偏偏是他 / 她"？
2. 台词是否符合人物与情境？排比抒情或直接告白本身不等于油腻。
3. 两人是否没有共同事件、却默认默契十足？
4. 冲突的解决是否符合其实际原因？可以通过解释和好，不为保留张力强加代价。
5. 表白是否有可理解的感情基础与时机？不要求一定挂在外部主线事件上。

## 感情线正反例五组

**组 1（无逻辑亲密→借"触碰障碍"放大每个动作的分量）**：反——男女主刚见面三章就深情对视、自动牵手，无铺垫无阻力，糖是工业糖浆。正——Leigh Bardugo《Six of Crows》中 Kaz 有触碰恐惧症，因此他每一次伸手、每一次握手都像仪式；"当他伸出手，读者屏住呼吸"。障碍（心理性触碰恐惧）让本可廉价的亲密变得不可替代。出处：Novel Concepts Publishing。

**组 2（直球表白→克制式"将溢未溢"）**：反——"我喜欢你很久了，做我女朋友吧"——无场景、无潜台词、无肢体刻度。正——久别重逢不写直接拥抱，写"他指尖颤抖着悬在她肩膀一寸的位置，死死扣进掌心，最后只哑着嗓子说了一句好久不见"。把想吞噬对方的欲望压进理智的壳。出处：抖音写作教学·网文感情戏。

**组 3（互补写成"保姆带娃"→双向兜底的互补）**：反——女主全程闯祸、男主无限收拾，读者只觉是育儿，CP 感归零。正——两人短板正好对应对方长处，遇事轮流兜底——女主冲动拔剑时男主冷静控场，男主慌乱时女主稳住大局。出处：抖音写作教学·CP 感五配方。

**组 4（确定关系即结局→确立后开新阶段张力）**：反——表白成功、确认关系，全书情绪随即 flat，后文只剩日常水字数。正——确立关系只是把外部阻碍换成内部问题。英文 slow-burn 指南强调：proximity without permission（物理靠近但不许行动）＋interrupted moments（几乎要吻又被打断）才是张力来源；确立后需引入新的"代价"（vulnerability becomes dangerous, what happens if the relationship fails）。出处：Shea Hulse、Olive Spencer。

**组 5（误会为虐而虐→误会承担"期待管理"）**：反——为拖进度硬降智，一方不肯听解释、另一方不肯说，读者愤怒弃文。正——误会是"减速带"，把"一定会在一起"的必然拖成"怎么还没在一起"的期待。三种变体：越描越黑写成笑点、解释永远差一步越拖越疼、知情者提前止损反手化解。误会的功能是制造期待，不是制造智商税。出处：抖音写作教学·误会与错过节奏。

## 感情线书目与创作谈

- 言情结构范本：晋江《2026 写作日志》第 15 章（作者与"小友"对话体拆解感情线结构）。
- 英文写作指南：Maizie Bennett（Character Chemistry）、Write with Harte、Shea Hulse（Slow Burn 完整指南）、Olive Spencer、Scriptum、LoveLines Studio（Push-Pull 节奏）。
- 可拆解正文样本：Leigh Bardugo《Six of Crows》（Kaz × Inej 的触碰障碍式张力）。
- 作者谈要点：chemistry 来自阻碍而非共识；"几乎"（almost）比"完成"更抓心；身体比嘴诚实。
