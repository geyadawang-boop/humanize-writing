## 阅读纪律

1. 先读路由，再读当前任务所需的一至三份；症状专章按需追加。
2. 历史分册中的固定字数、钩子秒数、句长配额与平台规则，都要按适用范围解释。
3. 来源标注带日期的资料不自动等于当前规则；涉及平台价格、投稿要求、法律条款时另查官方来源。
4. 文档之间冲突时，按 [SKILL.md](../SKILL.md) 的判断优先级链裁决，不各取一半。
