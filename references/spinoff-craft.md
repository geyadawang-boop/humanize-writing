# 网文番外与支线管理参考（番外五类 / 支线开合 / 三种咬合 / 台账模板 / 防失控）

本文件管**番外类型选择与支线的开、合、收、束**。与既有文件的分工：伏笔管理（"填坑番外"的上游是伏笔台账）在 foreshadowing-craft.md；多视角/多线叙事的声音与视角纪律在 viewpoint-craft.md；长篇架构总览在 novel-craft.md。核心立场：番外与支线都是"为主线服务的资源"，不是用来填字数的垃圾桶。

## 一、核心方法论

### 1. 番外的五种类型与时点

**按内容分：**
- **人物番外**：补一个配角/反派的前史或后日谈。
  例：主角团里那个早死的师兄，他年少时到底经历了什么。
- **时间线番外**：正片里跳过的一段空档，用番外补出来。
  例：主角闭关三年，这三年里外界发生了什么。
- **IF 线 / 平行世界番外**：在某个关键节点做不同选择，走另一条分支。
  例："如果那天他没有拔剑"。注意：IF 线不能改主线结局，
  只能作为平行假定存在，否则会冲淡正篇选择的重量。
- **日常番外 / 发糖番外**：主线高压间隙里的甜、闲、搞笑，
  类似动画 OVA 的功能——不推进剧情，但满足情绪。
- **填坑番外**：正文里埋了没收的伏笔，番外里交代。
  风险：填坑番外一旦写长，读者会觉得"你正文里为什么不写"。

**按时点分：**
- **正文中插（章末短番外）**：随更附赠，调节节奏；
  风险是打断主线紧张感，高潮卷里别插。
- **卷末番外**：一卷完结后松口气用，最安全。
- **完结后番外**：风险最低，读者已接受结局，随便发糖/补人物。
- **连载间歇期番外**：断更/请假期间维持热度用；
  风险是读者会把番外当成新主线催更。
- **节假日番外**：春节/七夕发糖，纯情绪福利，别塞大剧情。

### 2. 番外的作用边界（什么能做、什么不能做）

- **能做**：
  - 补人物弧光里没拍到的侧面；
  - 满足 CP 党 / 意难平读者的情绪需求；
  - 断更期间维持存在感；
  - 填掉正文实在塞不下的小坑。
- **不能做**：
  - 不能替代正文该写的关键戏（该写的决战拖到番外写=注水）；
  - 不能改主线人物关系（番外里把官配拆了=OOC 翻车）；
  - 不能泄露正篇还没揭晓的悬念；
  - 不能把番外写成第二部的预售，逼着读者为新设定买单。
- **一句话判断**：如果删掉这篇番外，读者对主线的理解会缺一块吗？
  不会 → 它是福利；会 → 它本来就该是正文。

### 3. 支线怎么开：为什么开、何时开

**支线的四种正当理由（至少占一条才开）：**
- 服务主题：用配角的处境从侧面印证/反讽主线主题。
- 人物成长：让主角在支线里被迫做出选择，改变对主线的态度。
- 世界扩展：通过一个新场景/新势力，让世界变大而不空。
- 节奏调节：主线长期高压后，用一段相对轻松的支线换口气。

**开启时机：**
- 太早（主线冲突还没立起来）：读者不知道该关心谁，支线像跑题。
- 标准做法：主线激励事件发生后、中点之前，引入第一条支线。
- 太多支线并行：长篇网文一般同时 2–3 条就够，
  超过 4 条读者记不住。
- 篇幅比例参考：主线 ≈ 70%，支线 ≈ 30%；
  支线一旦超过 40%，就要警惕"抢主线风头"。

### 4. 支线与主线的三种咬合方式

- **人物咬合**：支线里的配角后来进入主线（成为队友/敌人/关键证人）。
- **事件咬合**：支线里拿到的物件/信息/伤势，直接影响主线决战。
- **主题咬合**：支线人物面临和主角一样的命题，但给出不同答案，
  从而照见主角的选择。
  （这是最高级的咬合——支线不是另一个故事，是同一主题的另一个切面。）

### 5. 支线怎么收：时机、高潮、汇合、防失控

- **收束时机**：在主线进入终局前，按"重要性从低到高"依次收掉支线；
  主线留到最后解决。这样越往后焦点越聚。
- **支线高潮**：每条支线要有自己的小高潮和小结局，
  不能"开了就忘"。读者对"开多收少"非常敏感。
- **多线汇合**：终局前让各条支线的人物/资源/信息在决战点合流，
  让读者有"原来这里用上了"的爽感。
- **防失控四条警戒线**：
  1. 一条支线连续写超过 5–8 章还没回到主线 → 危险。
  2. 支线比主线更好看、评论区开始催支线 → 要么把它并进主线，要么砍。
  3. 新开支线时，上一条还没收 → 不要叠 buff。
  4. 支线人物抢戏到读者忘记主角是谁 → 立即拉回。

## 二、原则 / 公式 / 检查项

### 黄金原则
1. **番外是甜点，不是正餐**：番外写崩了不致命，正文写崩了致命。
2. **支线必须能被"删掉检验"**：
   删掉这条支线，主线会变弱吗？不会 → 它是注水，删掉。
3. **每条支线都要有自己的小开头、小高潮、小结局**，
   不能只开不收。
4. **人物一致性（OOC 红线）**：番外里的人物行为必须能被正文已建立的
   性格解释；不能为了发糖让冷面人突然话痨。
5. **时点即伦理**：高潮卷不插日常番外；解谜卷不发剧透 IF 线。

### 支线台账模板（开一条就记一条）

| 字段 | 说明 |
|---|---|
| 支线名称 | 一句话，如"镖局少主的身世" |
| 服务目的 | 主题 / 人物成长 / 世界扩展 / 节奏调节（至少选一） |
| 咬合方式 | 人物咬合 / 事件咬合 / 主题咬合 |
| 开启章节 | 例：第 47 章 |
| 预计收束章节 | 例：第 60 章前必须收 |
| 当前状态 | 开启中 / 发展中 / 高潮 / 已收束 / 冻结 |
| 与主线关联点 | 它给主线送什么（人/物/信息/主题对照） |
| 字数预算 | 例：8–10 章，超了就砍 |

### 完稿检查项
- [ ] 当前并行支线是否 ≤ 3 条？
- [ ] 每条支线是否都有"预计收束章节"？
- [ ] 是否有支线开了超过 10 章还没回到主线？
- [ ] 最近三章里，主角的戏份是否还占一半以上？
- [ ] 番外里是否出现了正文没铺垫过的新设定/新 CP？
- [ ] 番外是否抢了正篇尚未揭晓的悬念？
- [ ] 日常番外的篇幅是否明显短于主线单章？（应该更短）

## 三、正反例（均附出处）

### 正例1（支线咬合良好）
**《凡人修仙传》每到一新地域的本地势力斗争**（忘语，起点中文网连载）。
- 支线形态：韩立到一个新地图，卷入当地门派/家族争斗。
- 咬合方式：事件咬合（拿到丹药/功法/情报）+ 人物咬合（认识后续还会出场的散修）。
- 为什么好：单看每段都像独立冒险，但每段结束都给主角的主线修为/资源
  加了一块砝码，删掉任何一段，主角后面的实力提升就站不住。
（来源：网文教学类公开内容对"三线并行"的拆解，见第五节 URL。）

### 正例2（番外有价值）
**完结后补人物后日谈的常规做法**——晋江作者圈共识：
把番外分两类，一类是"结婚蜜月日常"这种甜宠；
另一类是"作者自己写正文时觉得遗憾、没写透的那一段"，
换个视角（下属/炮灰/反派）重讲一遍。
- 为什么好：第二类番外真正补了正文的情绪缺口，
  而不是单纯发糖；读者会觉得"作者懂我"。
（出处：晋江文学城论坛《没用的空星干货》帖，见第五节。）

### 反例1 → 修正（支线失控：疯狂写配角）
- ✗ 失控：玄幻中后期主角连续十几章不出现，
  这一章写二师兄的童年，下一章写反派的情人，再一章写小配角买马。
  美其名曰"群像"，其实是主线卡壳水字数。
- ✓ 修正：每个配角支线最多 3–5 章，
  且必须在章末把视角拉回主角；
  每条支线结束时，主角的处境/资源/认知必须发生一个可见变化。
（来源：抖音网文教学"3 个水剧情大法"对"疯狂写配角"的批评，见第五节。）

### 反例2 → 修正（番外 OOC 翻车）
- ✗ 翻车案例（公开讨论过的网文事件）：
  某长篇完结多年后出番外，把原著里性格极冷、
  与男主深度绑定的冰山女主，写成收了一名年轻男徒弟、
  签了全书最高规格灵魂契约的状态——粉丝大规模抗议，
  因为这破坏了正文建立的人物关系与情感归宿。
- ✓ 修正：番外动笔前先问三句：
  (1) 这个行为正文里的这个人会做吗？
  (2) 它会不会动摇读者对主线结局的信任？
  (3) 如果是 IF 线，是否明确标注"非正史"？
  三问答不上来，就不要发。
（出处：抖音相关讨论视频，见第五节。）

### 反例3 → 修正（番外注水）
- ✗ 注水：主线正写到决战前一夜，作者插了一篇三章的
  "主角和师妹上街买糖葫芦"番外，读者正在紧张点上被泼冷水。
- ✓ 修正：日常番外放在卷与卷之间的空档发；
  高潮卷内部只允许 1000 字以内的短番外，
  或者干脆不发。
