# 中文剧本格式：先遵守交付约定

格式优先级：用户/制作方明确模板 → 当次投稿方的具体要求 → 本页的一致、可读默认格式。英文 spec、中文文学剧本、舞台本、音频本、分镜/摄制本分别处理；不能把好莱坞规范称为所有中文剧本的强制标准。

本页吸收用户 U4 资料并纠正内部问题，使用自编示例；没有重新验证其中每份征稿启事，未声明全国统一行业标准。相关来源范围见 [knowledge-map.md](knowledge-map.md)。

## 1. 中文影视文学剧本默认体例

每场单独标题，包含稳定场号、地点、时间、内外景。例如：

    SC001  第1场  老城区公交调度室  夜  内

场号服务修订和交叉引用；章节/集号另列。电影也可用“1、调度室。夜。内。”，项目内统一即可。日/夜/晨/昏属于时间，内/外属于场景属性；需要精确钟点时可以写，不能为整齐删掉影响因果的时间。

动作另起段，写正在发生且可呈现的信息；人物名和对白清晰分开。默认“人名：台词”，不额外给整句对白加引号，但台词内引用仍按语言需要使用引号。括号只补必要且不易从情境读出的动作/对象/说话方式，不给每句固定情绪标签。

首次出场提供辨认人物所需的信息，不要求中文名变成大写；年龄等只在人物或制作确有需要时标注。字幕、屏幕文字、画外音、电话另一端等要让读者明确来源；不同团队对 O.S./V.O. 的使用可能有差异，先定义再一致使用。

## 2. 三列对照（自编示例）

| 中文场景标题 | 英文场景标题示意 | 文学叙述 |
|---|---|---|
| SC001 调度室 夜 内 | INT. DISPATCH ROOM - NIGHT | 夜班调度室只剩一盏台灯。 |
| SC002 公交车站 黎明 外 | EXT. BUS STOP - DAWN | 天刚亮，末班车站牌被雨淋透。 |
| SC003 公交车内 夜 内（行驶中） | INT. BUS - MOVING - NIGHT | 公交车颠过积水，车厢里空着一半座位。 |
| SC004 调度室 日 内（回忆） | INT. DISPATCH ROOM - DAY (FLASHBACK) | 她想起几年前父亲第一次让她值班。 |
| SC005 调度室 夜 内（回到现在） | INT. DISPATCH ROOM - NIGHT (PRESENT) | 耳机的电流声把她拉回这一夜。 |

第三列只是说明信息转换，不是直接等价的剧本正文。“她想起”还须选择画面、声音、旁白或其他呈现办法。完全在车内的场次不写“外（车内）”；确实交错车内外时说明组合或拆场。回忆的进入/退出要可识别，具体括号写法按模板。

## 3. 一小段完整正文（原创示例）

    SC001  第1场  老城区公交调度室  夜  内

    林岚把最后一辆车的磁牌挪到“已回场”。手停住。
    耳机里传来两下敲击。她看向时钟：23:41。

    林岚：七路？报车号。

    耳机里只有雨声。她重新把磁牌推回“运行中”。

    林岚：先别熄火。我找你。

    SC002  第2场  调度室门外  夜  外

    林岚撑开伞。值班门卫递来钥匙。

    门卫：你爸那辆？

    林岚接过钥匙，没有看他。

    林岚：今晚先找到人。

这段展示可见行动、可听信息与选择；不预设其符合任何特定分钟数或投稿要求。若用于音频，磁牌变化必须通过合理声音、话语或旁白传达；若用于舞台，则设计调度室与门外的空间转换。

## 4. 文学剧本与技术剧本

文学剧本主要写观众最终会经历的行动与信息。必要的视觉揭示、声音先入、重要转场可以写；“不能出现任何镜头语言”不是普适硬禁令。用户要分镜/摄制本时，可以增加镜号、景别、机位、运动、声音和时长等列，避免把这些列默认强加到所有创作稿。

“淡入”只有进入画面时有意义，“淡出”用于退出画面；不是每场或全文结尾的格式盖章。普通换场仅用下个场景标题通常已清楚，需要特殊切换效果再写。

舞台本采用人物表、幕/场、必要布景与上下场说明；音频本明确人物声线标识、对白/旁白、音效与音乐的进入退出。两者不要求全部使用 INT./EXT. 标题。

## 5. 排版与时长不混为一谈

- Markdown 草稿保持标题、空行、人物标识一致，不模拟英寸缩进。Word/PDF 正式交付再应用目标模板的字体、字号、页边距、行距、页码。
- 宋体小四、1.5 倍行距等可作项目选择，不能从若干征稿启事推成全国唯一标准；当次征稿的字数与梗概要求也只约束那次投稿。
- 不把“一页一分钟”“中文一页30–45秒”或“一分钟300字”当通用换算。排版、对白速度、动作和静默都会改变时长，按场估时并试读。
- 资料中将中文字符笼统称作“比例字体”并据此推出固定秒数，推导不足，不采纳该换算。
