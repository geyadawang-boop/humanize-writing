# 剧本：从故事承诺到整部正文

用于电影、影视剧集、竖屏短剧、舞台和广播/音频剧的原创、续写与改编。只改一场或几句对白时直接处理该范围，不另建整套项目。格式见 [chinese-screenplay-format.md](chinese-screenplay-format.md)，来源与发布要求见 [content-boundaries.md](content-boundaries.md)。

校园/青春剧本另看[校园创作指南](campus-youth-craft.md)。中国境内制作或公开播出涉及的内容要求、未成年人节目适用范围及微短剧规则，按[来源核对页](china-screen-content-boundaries.md)逐项判断；内容、制作与许可是不同的验收层，不承诺过审。

## 1. 媒介与连续性分别判定

媒介决定信息怎样抵达观众，连续性决定故事单元怎样闭合。题材、横竖屏、时长、更新与付费方式不能互相替代。用户明确的交付物优先；大量心理、对白或动作不使小说自动变成剧本。

| medium | 对象 | 正文特别检查 |
|---|---|---|
| film | 独立短片或长片 | 全片承诺在约定结尾处理；不预设单主角、三幕或固定页数 |
| screen_series | 横屏/其他常规影视剧集 | 单集变化与系列状态相容；不能仅将长片等长切开 |
| vertical_series | 为竖屏观看设计的剧集 | 核心信息、出入画和动作清楚；短集也可有停顿、人物复杂度和结局 |
| stage | 现场表演 | 上下场、空间、换景可实现；三一律、对白主导、固定时长都是选择 |
| audio | 广播/音频戏剧 | 人物、位置变化和动作后果可听懂；对白、旁白、音效、静默各有功能 |

- standalone：约定的一部独立闭合。
- serial：主要因果按顺序累积，单集可只完成阶段任务。
- episodic：主要单元有相对独立的目标、过程和结果；单元可跨数集，写清边界。
- hybrid：确有独立单元，也有持续主线。多线、多时空、每集发现一条线索，都不足以单独证明 hybrid。

3–20 分钟等中间时长也按这两个维度处理，不设路由空档。

## 2. 范围与底稿

记录片名/ID、媒介、受众、类型承诺、目标时长或总集数、要交付的季/部/集范围、格式、人物与场景条件、资料边界、现有正典、结局承诺。未知但不妨碍起草的选项记工作假设；会改变整部范围的集数/时长/改编目标在大规模起草前明确，不偷偷替用户决定。

整部项目使用 [screenplay-bible.md](../templates/screenplay-bible.md)、[screenplay-scene-list.md](../templates/screenplay-scene-list.md)，系列作品加 [screenplay-episode-outline.md](../templates/screenplay-episode-outline.md)。独立作品的分集表标明 N/A 和理由。小项目可合并文档，已有合格结构继续使用，不为模板重建原稿。

“尚未决定”不填成默认事实。项目状态索引正文与正典，不能取代正文。

## 3. 六步写完

1. **故事承诺**：谁想完成什么，主要阻力、选择与后果；结尾回答什么、允许什么余味。开放结局也要有设计。
2. **总纲与弧线**：连成因果链，高潮来自已铺设的人物选择/机制；三幕、序列等是可选工具，不按页码填空。系列作品分别写单元、季、全系列的问题与闭合点。
3. **分集/分场**：记录进入与离场条件、实际信息/关系/节奏作用及后续依赖；目标、障碍、行动、发现、转折按本场功能观察，可以无明显外部转折或标不适用，不为填表造事件。完整项目按约定从开端抵达结尾，中段不留“展开冲突若干集”。
4. **真实正文**：写场景标题、动作/舞台/声音提示及本作需要的完整台词；无台词片段保留必要表演提示，不硬加解释性对白。梗概、分场表、摘录或精彩片段不代替中间场次。短项目写全文，长项目分批但保存接续状态。
5. **整合修订**：先审因果、人物状态、线索与结尾，再审场内动作、声口、格式；局部台词任务不倒逼全剧重构。
6. **交付核验**：核范围、正文、连续性、时长和收束，报告真实阶段与待修问题，不自称已可投拍或过审。

改编时在第 2 步附取舍表：原作核心承诺、保留关系/事件、合并或删除的线、转译办法、因果影响。心理可通过选择、动作、声画关系、旁白或独白转译；不要把所有心理都换成摸杯子、掐烟、攥拳头。

## 4. 系列剧分集控制

每集回答：跟随什么问题，发生什么变化，观众获得什么回报，什么状态/问题传入下一集。回报可以是解题、情绪、关系或理解，不必集集反转。

A/B/C 是本项目的线索名，不固定等于案件/恋爱/笑料，也不固定占比。用因果、主题对照、人物选择或节奏交织建立联系，不强制第三幕合流。静态人物、失败弧线也可成立，不强制每集成长一格。

钩子记录：提出场次、对观众的承诺、计划回应位置、实际回应与后果。按承诺尺度兑现，没有通用“下集前五分钟必须解答”。可用危机、信息、关系选择、反转或余波，也可平静收尾。季末先履行本季承诺再留续篇；全剧终不为追更强留无法偿还的核心悬念。

cold open、teaser/acts/tag、广告断点、五段式短剧节奏仅在项目适用时用。更新、画幅、预算影响组织方式，不能直接推出必须连载/单元或必须高/低预算。

## 5. 制作意识与时长

- 影视动作可呈现；必要时指出观众必须看到/听到的信息，省去无功能的设备、焦距与机位指令。用户要分镜/摄制本时组织相应技术内容。
- 舞台上下场、灯光/声音/换景可执行；多地点不自动判错，默剧/形体不强制靠对白解释。
- 音频不能只写“她看见钥匙”；设计可听的发现与后果，不让角色为听众复述彼此早知的信息；必要旁白可直接用。
- 预算敏感项按真实项目记录：动作、群演、动物、夜戏、儿童参与、特效和多地点等。未知则标假设，不虚构报价。
- 时长先分场估计再汇总，说明动作、停顿、换景与声画段的假设；实际做了朗读或排演才记计时条件及结果。未试读标估计，页数/字数系数和模型口读模拟不当实测，桌读也不等同场地可听度验证。文字稿可依委托交付估时；明确要求实际试演或实测时长的项目，未完成的实证单独列明。

## 6. 每批后的连续性维护

新增/改变事实写回正典：人物知道什么、关系、道具/线索位置、伤情、时间及已履行/待回应承诺。区别计划与正文已发生；重写前文时列受影响的后续场次，同时修正文与账表。

中断前保存本批正文、已完成/待写场次、下一场进入状态及待决事项；续写读取最小上下文。容量只够一批时如实报告剩余范围，不以“其余按此写”宣称整部完成，也不虚称已安排后台续写。

## 7. 完结看正文证据

| 检查 | 通过依据 | 不能代替的信号 |
|---|---|---|
| 范围 | 约定集/幕/场均有完整正文，清单与文件相符 | 文件存在、只有标题、提纲、重复段落 |
| 主线 | 高潮/结尾处理核心冲突，有可定位场次 | 台账写已回收，正文没发生 |
| 人物 | 选择与变化/不变有过程，知识和行为一致 | 小传完整、结尾突然宣言 |
| 承诺 | 重要线索/关系债有回应或明确开放设计 | 全留下一季，结尾临时解释一切 |
| 媒介 | 影视可呈现、舞台可演、音频可听，格式一致 | 各媒介套同一“可拍性”规则 |
| 时长 | 按委托给估时与假设，或提供实际试读/试演范围及记录；未实测明确标记 | 字数除常数、模型默读或无演员记录却宣布精确分钟/现场清晰可闻 |
| 审读 | 阅读开端、中段、转折、高潮、结尾及跨段关系，记录问题与修复 | lint 低分、关键词齐、全绿勾选 |

自动检查与内容审读分开报告。没有外部读者、演员或编辑反馈，不冒称已获其认可。
