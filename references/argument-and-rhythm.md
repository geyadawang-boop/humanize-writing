# 对照、句段节奏与工整化

用于新写和改稿时复核无依据的反衬、虚假二选一、连续碎句，以及为了整齐而凑句、凑段的问题。先保留用户目标、原文事实与人物声音，再决定是否调整；这些形式不能单独用来鉴定作者身份。用户说“不必对仗工整”时，把它作为本稿的声音偏好，不新增句长、对偶次数或段落比例门槛。

## 1. 先把判断说清楚

直接交代对象、判断与已有依据。需要限定时说明条件、范围或程度；需要比较时说明比较维度。不要为抬高后项，临时编出一个低劣的前项或替读者安上错误观念。

遇到“不是A而是B”“并非A，真正的是B”“你以为A，其实B”“A只是……，B才……”或英文 not X but Y / this is not about X 等结构，回读两端的实际关系：

- 前项确实被提出过，或确有纠错、排除、比较的需要吗？原文与证据是否支持否定它？
- 两项是否可以并存，或只是层次、条件、程度不同？若是，按实际关系表达。
- 去掉否定半句后，主张及依据是否仍然完整？若完整，直接陈述往往更清楚。
- 不只替换连接词：把“不是A而是B”改成“真正的B远超A”，仍可能保留同一处无依据的贬抑。

也要检查没有否定词的高低排序，如“A只管表面，B直抵本质”“普通人看A，懂的人看B”。换成“既A又B”前仍须核实两项都成立；删去前项后若只剩空泛赞美，应回到已有事实说明判断，材料不足时收窄结论。

**两种相似句式要分开命名**：让步—反驳（refutation pivot）与虚构对照（fabricated contrast）字面接近，性质相反，不能用同一条规则处理。

- **让步—反驳**：反方观点**确实被提出过**（有姓名、来源、群体或可归属的说法），且两端在该前提下确为不相容关系。此时“虽然承认这一点，但……仍不成立／并不意味着”是论证工艺的规定动作——它承载的是真实让步与真实转折，**不得因句式相似而削弱或删去**。若为了“不像机器”把让步句改成平铺直叙，反而丢掉了文章正面处理反对意见的能力（详见[议论文工艺](argumentative-craft.md)第 3 节：一段只咬一个反论、己方笔墨多于对方）。
- **虚构对照**：前项 A 从未被任何人提出，是为抬高 B 临时立起来的靶子，或两端本可并存却被写成排斥关系。这才是本节针对的对象，按上面的问句处理。
- 判别动作只有一个：**回去找 A 有没有真实出处**。有，就是让步；没有，就是造靶。

**限定词与绝对句按来源判定，不按词形判定**：“可能／通常／在……条件下／大概”与“必然／所有／绝不／任何”都不因为出现或被删改而自动变好或变坏，判据是**它有没有对应的真实例外**。

- 全称主张先找一个反例：找得到真实反例却写成“所有”，就收窄或补上限定；这个限定是实质性反驳留下的痕迹，不是修辞礼貌。
- 已有充分授权支持的结论仍写“可能”，是另一种失准：有些前提确实授权毫不含糊的判断，此时“必然”比“可能”准确。
- 对每句均匀撒缓冲词（尤其段首堆“想必／部分／许多”）既不含糊地躲开了责任，也制造新的空话；本可确证的数学、逻辑与法定条件场合不必弱化。
- 不得把“加限定词”表述为降低被判 AI 概率的手段；这只服务表达准确（对应[议论文工艺](argumentative-craft.md)第 2 节）。

**按功能保留**：有依据的事实纠错、概念排除、用户要求的比较，以及服务人物争执、讽刺或不可靠叙述的表达。角色偏见需要能归属于角色；编辑者不可自行把它升格为事实，也不要把有冲突的台词统一改成温和说明。

### 教学例：事实保持不变

- 无依据排斥：“写小说靠的不是文采，而是逻辑。”针对已有问题可收窄为“这篇小说先要修复人物行动的因果衔接”；仅在原稿确有相应问题时作此判断。一般讨论可写“文采与逻辑分别影响表达和叙事可信度”。
- 人为树靶：“你以为读者要的是漂亮句子，其实他们要的是真实。”若没有读者反馈，去掉代言读者的断言；针对实稿说明哪一处信息或人物反应需要调整。
- 必要纠错：“通知写的不是周五，而是周四。”核对通知后可保留；不能因句式相似删除日期区别。
- 人物争执：“你要的不是解释，是我认错。”若这是角色此刻的判断，保留冲突立场和说话方式；不要补写另一方确实怀有该动机。

## 2. 让句子容纳完整的意思

以动作链、观察范围、因果与时间关系、指代和信息重心决定停顿。长句、短句、均匀句群都有适用语境；句长差与短句比例均不作为自然程度或成稿门槛。

出现连续短句时，查看同一个主语和动作是否被切散，解释与结果是否失去联系，停顿是否让每件小事都承受同样重音。确有阅读问题时，把关系紧密的信息合成连贯句群，调整主干与标点；不靠逗号一串到底，也不补原文没有的因果、动作、心理或感官细节。

长句主干被多层修饰遮住时，可重排或拆分。不要默认一句只容纳一个动作，不规定每几个长句插短句、短句至少占多少，也不规定收尾必须单独用短句。

**按功能保留**：对白轮次、诗歌分行、剧本动作拍点、紧迫口令、人物喘息、意识中断、刻意留白或简练声口。新写时根据场景安排，改稿时先判断是否属于作者有意选择。

### 教学例：不新增事实或动机

碎句稿：“她走到窗边。推开窗。雨停了。楼下的车还没走。她拿起电话。”
连贯稿：“她走到窗边推开窗，雨已经停了，楼下的车还没走。她拿起电话。”
保留拨电话的落点；没有把它解释成雨停或车未走的结果，也没有编出她打给谁。若原稿有意逐拍观察，可保留相应停顿。

另一组：“他早上起晚了，所以没吃早饭，跑出门后还是迟到了。”因果已由原稿给定，可保留必要连接；无需为追求短句改成“起晚。没吃。出门。迟到。”

### 分段和细节按功能选择

段落可依据主题、场景、说话人、信息层次和稿约划分；长短接近或差异明显均可能合用。先检查关系能否读懂、重心是否清楚，不为长度比例拆散同一意思，也不把不同说话人的对白强行合段。档案、日记等碎片形式在时间、主体或前后联系不易理解时补定位，不按固定间隔插评注。

具体感可以来自动作过程、物件状态、空间关系和信息差，未必需要日期、数字或地名。非虚构只用已有或可核信息，保持数值精度、范围与不确定性；不把“约”“十余”等改成未经证实的精数。虚构按世界设定、视角和场景作用选细节，保持前后数量一致，不为指标添加无关地点、编号或经历。

## 3. 工整是否挤掉了本来要说的事

先按事实、事件或论证的联系展开，不预先为每段留一组对照金句。工整造成的问题可能出现在整篇：段段先否后肯，连续采用“A负责……，B负责……”，或每一节都以相同长度的三项排比收尾。需要修改的是由此产生的重复、虚假分工和重心失真，不能仅凭几个句子长度接近作结论。

把看似成对的两半单独读一遍，检查后一半有没有新增信息，是否为凑字数添了材料没有的评价或含义。若只是换词重说，可合并或删去重复；若它们实际是条件、过程或程度关系，就把关系说清楚。标题和段落不必共用同一骨架，不为“自然”另造一套每长必短、每齐必乱的模板。

教学材料只给出：“维修点周三暂停，周四恢复。已经预约的人可保留原顺序。”若改成“暂停的是一天，延续的是承诺；改变的是时间，不变的是温度”，日期与预约信息被挤掉，还加入了没有材料支持的评价。可写成：“维修点周三暂停，周四恢复，已预约的先后顺序不变。”这里的取舍依据是通知用途和已有事实。

对联、格律要求、用户指定的排比文案、便于核对的技术条目，以及人物有意说出的口号，都可能需要整齐形式。原文已清楚时允许不改；不通过打乱步骤、拆散表格、抹掉人物修辞或随意删半句来消除对称。用于维护报告的可比条目也不必假装口语散文。

**工整的问题在两头，不在中间**。古典文献给出的机制今天仍可用：昆体良批评警句过密，理由是它把语篇碎成“一堆碎片而不是一个肢体系统”，每句之后听众都要重新起步；同一份文献**也谴责另一个极端**——一味平实、不敢攀登，结果是永远平坦。亚里士多德解释过度规整的节奏为何削弱说服力：它让听者开始等待下一个节拍，注意力被形式本身劫持，内容反倒退场。

因此本节的批评对象始终是同一样东西——**形式占了内容的位置**，而不是“整齐”这一特征本身。据此得到下限保护：不得为了破坏整齐而牺牲可读性与力度，不得为“看起来不像机器”故意打乱句序、拆散对偶或制造参差。为凑对仗造整齐，与为躲检测毁整齐，是同一种错误的两个方向。

## 4. 实际复读与停止条件

先看对照是否有依据，再读同一段落的动作、指代和停顿；连读相邻段落，检查是否反复套用同一种起收或成对句式。判断要落在具体文本位置。对有问题的句群尝试最小改动，核对事实、立场、声音与阅读负担。修订后仍可保留长句、短句和对照。

用户只要成稿时交付成稿；只查不改时只报问题；原稿已经合用时允许少改或不改。不把一份好例子当所有小说、网文、剧本和文章的统一声音。

## 5. 工具边界

v0.41 的短句比例与已识别的重复“不是……而是……”只作零权重观察；v0.42 将句长标准差也改为零权重观察，取消均匀句长的14/7分及高标准差的认可标记。不设句长目标区间，也不为变化统计值把连贯意思拆碎或用逗号连成长句。静态程序不能判断前项真假、是否属于人物立场，也不能证明句群已经顺畅；v0.43再将段落长度与数字等锚点的正则匹配密度改为零权重观察；有限正则会漏掉具体行动，也可能匹配无关编号。两项均不设目标、不给高差异或高密度认可标记；其他旧启发式仍须按文体复读。

前后比较须固定规则版本。v0.40→v0.41、v0.41→v0.42、v0.42→v0.43 的分数下降可能完全来自计分改动，不能记为文风提高或外部AI检测率降低。

v0.44修订指导与示例，未调整脚本、权重或阈值，也没有新增“对仗率”。工整的用途、对照的依据和停顿的效果均须回到文本判断。
