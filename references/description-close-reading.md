# 章节精读与范文技法拆解

> 属于[描写方法与章节精读](description-craft.md)的分册。按问题进入本页，不必回读整包。

## 九、章节精读·技法维：六维框架

理论背一百条，不如拆三篇范文。每读一个章节，按**技法维六维**记笔记（同一批范文的**功能维**拆解——章节目标/节奏曲线/信息量/钩子——见 exemplar-close-reading.md §18，两套拆法互补）：

1. **人物出场**：第一个人物是怎么立住的？用了什么细节？
2. **叙事视角**：谁在讲？距离多近？有没有 FID？
3. **环境描写**：环境三层（物理/社会/心理）怎么配？有没有空镜？
4. **对话与潜台词**：遮住名字分得出来吗？潜台词在哪？
5. **节奏与结构**：场景四要素（目标/冲突/转折/结局）怎么配？时距怎么切换？
6. **主题/伏笔**：这一章埋了什么？主题在哪个细节里漏出来？

## 十、范文技法拆解三篇

### 10.1 《水浒传·林教头风雪山神庙》

**情节位置**：林冲被陷害发配沧州，看守草料场。大雪夜出门买酒，回来草厅被雪压塌，只好暂宿山神庙；恰好听见陆虞候等人在庙外放火谋害他——林冲忍无可忍，杀仇人，雪夜上梁山。

**六维拆**：
1. **人物出场**：林冲不是一上来就反的。刚到沧州还想着"待晴雪了却回去"——还是安分守己的教头。**人物弧光在这一章完成从"忍"到"反"的转折**。
2. **视角**：第三人称全知，但贴林冲极近。风雪、酒、火石、花枪——所有感官都是林冲的。
3. **环境描写**：雪是主角。从"那雪正下得紧"到"越下得紧了"——鲁迅赞一个"紧"字"境界全出"。环境不是装饰，是**把林冲一步步逼到山神庙的力量**（物理→社会→心理三层全在；雪同时是 2.4.2 说的"环境驱动情节"的引擎）。
4. **对话**：李小二夫妻偷偷议论陆虞候，半遮半露，林冲听后问"高太尉？"——潜台词全在。庙外陆虞候四人放火后的对话直接交代阴谋——林冲在庙里听，读者也听，dramatic irony（戏剧反讽，见 rhetoric-craft.md 反讽三型）拉满。
5. **节奏**：买酒（慢）→ 草厅塌（转折）→ 暂宿山神庙（停顿）→ 听见外面说话（快）→ 杀人（爆）。**时距切换教科书**（时距五型见 timeline-craft.md）。
6. **主题/伏笔**："逼上梁山"四个字全在这一章。前面所有隐忍，被这场雪和这把火一笔勾销。

**可学**：环境如何成为情节的推手（雪不是背景，是主角）；人物弧光在一章内完成转折；"紧"这种单字诗眼的力量（诗眼方法论见 prose-flow-craft.md）。

### 10.2 《红楼梦·林黛玉进贾府》

**情节位置**：黛玉母亲去世，被外祖母接进荣国府。这是读者第一次进贾府——曹雪芹借黛玉的眼睛，把整个贾府的人物、格局、规矩一次性立起来。

**六维拆**：
1. **人物出场**：王熙凤出场是中国小说史最经典的出场——"未见其人，先闻其声"："我来迟了，不曾迎接远客！"人还没进来，声先到，全场一静，黛玉纳罕。然后是她的打扮、她的夸黛玉、她的哭、她的转悲为喜——三页纸，一个泼辣、圆滑、有权势的女人全立住。
2. **视角**：第三人称，但全程贴黛玉——黛玉看到的、听到的、想到的、她的谨慎（"步步留心，时时在意，不肯轻易多说一句话，多行一步路"）。**这是 Deep POV 的中国古典版**。
3. **环境描写**：贾府的建筑、陈设、仆人数量、吃饭规矩——全通过黛玉的眼睛一层一层看。不写"贾府很豪"，写她看到的"赤金九龙青地大匾""大紫檀雕螭案"——社会层（这是侯门公府）和心理层（一个穷亲戚的紧张）全在。
4. **对话**：黛玉和邢夫人、王夫人、宝玉的对话——每个长辈说话方式不同，黛玉回话句句谨慎。宝玉一见面就"这个妹妹我曾见过的"——疯话里藏着前世伏笔。
5. **节奏**：一路进门（慢，铺陈）→ 见王熙凤（爆）→ 见众亲戚（缓）→ 见宝玉（爆，摔玉）。**两次爆点夹一次缓，节奏绝佳**。
6. **主题/伏笔**：宝黛初见的"这个妹妹我曾见过的"是木石前盟的伏笔；黛玉的"步步留心"是她一生寄人篱下的基调；王熙凤的笑声是她最终悲剧的预告。

**可学**："未见其人先闻其声"的出场设计；借一个外来者的眼睛立整个世界（"陌生人视角"立 setting）；一章内立住一群人物，且每个人说话方式不同。

### 10.3 《傲慢与偏见》第一章

**原文开篇**："It is a truth universally acknowledged, that a single man in possession of a good fortune, must be in want of a wife."（凡是有钱的单身汉，总想娶位太太，这已经成了一条举世公认的真理。）

**情节位置**：班纳特家五个女儿待嫁。新邻居彬格莱先生有钱，班纳特太太迫不及待想让女儿嫁他。第一章写班纳特夫妻关于这件事的一段对话。

**六维拆**：
1. **人物出场**：班纳特先生（冷幽默、爱逗妻子）和班纳特太太（肤浅、急切、话多）——两个人一场对话就全立住。**没有外貌描写，全靠对话节奏和内容**。
2. **视角**：第三人称全知，但开篇第一句是**巨大的反讽**——"举世公认的真理"其实只是班纳特太太这类人的一厢情愿。叙述者在第一句就和读者结成同谋，嘲笑班纳特太太。这是**自由间接语气（FID）+ 反讽**的经典。
3. **环境描写**：几乎没有。这一章全是对话，环境退到幕后。奥斯汀证明：**人物戏不需要大段写景**。
4. **对话与潜台词**：班纳特先生句句逗妻子——"他和我们的女儿有什么关系？""我自己去拜访他。"班纳特太太急得不行。遮住名字，两个人的声音完全分得出来。
5. **节奏**：全章就是一段夫妻对话，短、快、句句有戏。结尾班纳特太太那句"你真叫我难受"和班纳特先生的冷幽默——余味不绝。
6. **主题/伏笔**：婚姻与财产、性别与地位、傲慢与偏见——全书主题在第一段反讽里已经点出。

**可学**：开篇第一句就立住叙述者的声音（反讽腔调）；两个人一场对话立住一对夫妻；反讽叙述如何和读者结成同谋。

## 十一、精读五步法

1. 先读一遍，不做笔记，看故事。
2. 第二遍，按六维记笔记。
3. 第三遍，**仿写**——用范文的手法写一段你自己的故事。
4. 把你仿写的段落和原文对比，找差距。
5. 一个月后再读一次，你会看到上次没看到的东西。

> **结语**：描写的训练不是学会"写得美"，而是学会"写得准"。准的标准是：**这段描写删了，故事真的会少一块。** 每写一段描写，都问自己这句话。
