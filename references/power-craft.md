# 战力体系防崩参考（硬软规则 / Sanderson 三定律 / 升级节奏 / 战力审计 / 防龙珠化）

本文件管**力量体系层**——战力设定怎么搭、怎么防崩、怎么跨卷不失守。与既有文件的分工：武侠世界观/门派/侠义精神在 wuxia-craft.md；伏笔与悬念管理在 foreshadowing-craft.md；升级爽感与读者心理在 novel-craft.md。适用对象：玄幻/修仙/奇幻/超级英雄等带"升级"的长篇类型小说；核心命题：如何让主角一路变强，却不让张力随数值一起通货膨胀。

## 一、核心方法论

### 1. 战力体系设计：硬规则 vs 软规则
- **硬规则**：明确等级/数值/段位（如炼气→筑基→结丹→元婴；序列9→序列0）。优点是读者可预期、可推演；缺点是数值易膨胀。
- **软规则**：描述性、相对性（"此人深不可测""一掌之威山崩地裂"）。优点是留白；缺点是容易"为剧情临时加强"。
- **选型建议**：长篇连载优先"硬骨架+软血肉"——等级框架硬（几级、每级能做什么、代价是什么），具体描写软（不堆具体数字）。
- Sanderson 第一定律：作者用魔法解决冲突的能力，与读者对该魔法的理解程度成正比。读者越懂规则，越能享受智斗式解法；规则越模糊，越像作者开挂。

### 2. 战力必须与世界观绑定
- 力量来源要自洽：力量从哪来？（魔药/灵气/神之血/科技）为什么会稀缺？
- 必须有**限制与代价**：Sanderson 第二定律——限制比力量更重要，因为限制制造艰难抉择。
- 规则不能为剧情临时打破；要打破，必须提前埋"例外的代价"。

### 3. 等级间差距设计
- 明确每级差距量级：是碾压级（低阶对高阶连还手都做不到）还是切磋级（同阶内有来有回）。
- 越级挑战必须**有条件、有代价、有上限**：靠法宝/阵法/偷袭/献祭/信息差可以小越一级，但不能次次越两级。
- 《凡人修仙传》式"境界即天堑"：同阶内初期/后期可差十倍战力，跨大境界几乎不可能正面胜——这种森严感反而是张力来源。

### 4. 升级节奏
- **成长曲线非线性**：前期快（给爽感）、中期稳（积累资源与代价）、后期慢（接近天花板，转向其他维度）。
- **升级 ≠ 数值变大**：升级可以是——能力多样化（多一条途径/多一张底牌）、技巧提升（把已有能力用得更巧）、认知突破（理解规则本质）、资源/人脉/情报扩张。
- **突破代价设计**：时间（闭关数十年）、资源（珍稀材料）、风险（失控/走火入魔）、副作用（寿命/理智/人性损耗）。杜绝"顿悟就变强"。

### 5. 防"龙珠化"死循环
- 典型病症：主角变强 → 敌人更强 → 主角再爆种 → 敌人再更强（Z字上升，数值指数膨胀）。
- 解药：用**非战力变量**维持张力——智慧、资源、同盟、规则利用、信息差、情感赌注、道义困境。
- **设定战力天花板**：开书前明确"世界最强是谁、有多强"，所有角色在这个框架内活动。主角接近天花板后，张力来源从"谁拳头大"转向"立场之争/规则博弈/人性代价"。
- Sanderson 第三定律：扩展已有体系的应用，而不是不断加新体系。每加一层新力量，老规则就贬值一次。

### 6. 防战力崩坏四法（与打斗写作联动）
- **先定天花板**：开书前写死世界战力上限（神/天帝/旧日），列一张"天花板说明"。
- **规则优先**：每条能力写清"能做什么/不能做什么/代价是什么"，规则不为剧情服务。
- **跨卷对照表**：每卷结束更新一次战力总表（见模板）。
- **战力审计**：定期检查——是否有角色战力突然漂移？是否有前后矛盾？前期BOSS后期是否被无故降级？

### 7. 跨卷战力管理
- 维护战力对照总表（见下节）。
- **旧角色战力漂移问题**：前期BOSS在后期如何处理？三选一：
  1. 干脆不登场（让他留在旧地图，江湖只留传说）；
  2. 给合理解释（他也在进步/他有特殊底牌/他转职为非战力角色）；
  3. 用非战力方式解决（不靠打，靠智、靠势、靠规则）。
- 最忌讳：前期吹上天、后期当杂兵，毫无交代。

## 二、原则 / 公式 / 检查项

### Sanderson 魔法三定律（可直接套用到任何力量体系）
1. 作者用魔法解决冲突的能力，正比于读者对该魔法的理解程度。
2. 限制 > 力量（constraints create hard choices）。
3. 扩展已有魔法之前，不要急着加新魔法。

### 战力不崩的三条硬指标
- **可推演**：读者读到一场战斗前，能根据已有规则猜"谁可能赢、怎么赢"。
- **有代价**：每次越级/爆种都付出了读者能看见的成本（血、寿、理智、资源、盟友）。
- **有上限**：全书存在一个明确的"天花板"，主角的终点是接近/突破它，而不是无限翻番。

### 战力对照总表模板（每卷更新）
| 字段 | 说明 |
|---|---|
| 角色名 | 主要登场角色 |
| 当前等级/序列 | 本卷结束时所处位阶 |
| 关键能力 | 3条以内核心能力 |
| 限制/代价 | 能力的副作用与短板 |
| 战力定位 | 同阶中/越级能力/天花板下第几档 |
| 上次更新卷 | 第X卷 |

### 战力审计清单（每卷结束过一遍）
- [ ] 本卷主角升级了多少？是数值变大，还是能力/技巧/认知变多？
- [ ] 本卷新登场敌人比上卷敌人强多少？这个差距有规则依据吗？
- [ ] 有没有"临时爆种解决BOSS"？爆种的代价写出来了吗？
- [ ] 前期重要角色本卷还登场吗？他的战力相对主角合理吗？
- [ ] 本卷加了几条新规则/新能力？是深化旧规则还是另起炉灶？
- [ ] 天花板被突破了吗？突破是计划内的终局节点，还是剧情逼的？

### 膨胀预警信号
- 战斗描写开始堆形容词而不是写战术（"恐怖如斯""毁天灭地"）。
- 配角没人能上场，只能主角单挑。
- 老读者开始讨论"现在战力到底多少了"却算不清。
- 敌人变强的理由是"他是更强反派的手下"（纯层级堆叠）。

## 三、正反例（均附出处）

### 正例1：爱潜水的乌贼《诡秘之主》——22条序列途径+扮演法
- 世界设22条神之途径，每条途径从序列9（最低）到序列0（真神）共10阶；每阶能力明确（占卜家→小丑→魔术师…），高序列有"唯一性"与"非凡特性守恒"——同途径序列1全球最多3人，序列0唯一，导致高序列天生死敌。
- 升级不靠顿悟：必须用"扮演法"消化魔药（长期践行序列象征身份，否则失控畸变）；力量与疯狂、代价绑定，"每变强一步都离失控更近一步"。
- 出处：起点中文网诡秘之主资源站·神之途径（m.qidian.com/ziyuan/guimizhizhu/post/yueliangtujing）；抖音百科"诡秘之主序列途径"条（m.baike.com/wiki/诡秘之主序列途径）；潇湘书院诡秘百科（xxsy.net/baike/axdj3teuxidd）。
- 要点：硬规则（22途径/10阶/唯一性）+ 非数值维度（扮演法、精神污染、人性代价），是"规则优先、代价绑定"的范本。

### 正例2：忘语《凡人修仙传》——森严境界与锯齿成长曲线
- 人界篇境界（炼气13层→筑基→结丹→元婴→化神）差距为"天堑"：普通筑基初期可碾压五六个炼气巅峰；同境界初期/后期战力差可达十倍；韩立一身外挂也几乎不跨大境界杀敌，遇高境老怪多为"韩跑跑"式逃命。
- 成长曲线锯齿状：新地图先弱势适应，再靠小瓶灵液、傀儡、符箓、阵法等"资源溢出"逐步攀升，而非线性无敌。
- 出处：凡人修仙传百科·Power Progression Curves（immortalascension.com/en/timeline/power-level-timeline）；Han Li's Power Evolution（immortalascension.com/en/rankings/han-li-battle-evolution）。
- 要点：等级森严+越级极难+成长靠积累而非爆种，张力来自"活下去"而非"谁更强"。
- 附带警示：灵界篇后叠加炼虚/合体/大乘，化神人界顶峰在灵界降格为结丹初期，被部分老读者批评为"修为贬值、升级循环"——这恰好说明地图扩张时战力对照总表必须重做。

### 反例1：鸟山明《龙珠Z》——数值膨胀的教科书
- 赛亚人篇数值尚严谨（拿帕4000、贝吉塔18000）；界王拳引入"战力做乘法"（3倍/4倍），那美克星篇弗利萨第一形态即53万、最终形态涨到1.2亿，常规修炼被数学上封死；人造人篇后作者本人放弃再提战斗力数值。
- 评论界共识：界王拳的"倍数"口子一开，后续指数膨胀不可收拾；"濒死复活变强"的赛亚人设定让修炼与努力贬值。
- 出处：bytecosmico《The Exact Moment Dragon Ball Power Scaling Broke Forever》（bytecosmico.com/en/dragon-ball-z-frieza-power-scaling-broken-analysis/，含那美克星篇数值崩坏拆解）；AnimeNagi《Dragon Ball: Is Super Scaling Really Out Of Order?》（animenagi.com/super-scaling-really-order/，讨论后期变身形态与既有体系的冲突）。
- 教训：一旦引入"倍数增幅"且副作用被弱化，数值天花板就形同虚设；后期靠"变身新形态"续命即 Sanderson 第三定律所警——不断加新体系而非深化旧体系。

### 反例2：部分后期战力膨胀网文
- 通病：地图一换、境界一加，前期BOSS集体变杂兵；主角靠"顿悟/血脉觉醒/老爷爷传功"无代价越级；战斗退化为"谁气场大"。
- 教训：对照本专章"膨胀预警信号"逐条自查。

## 四、书目与创作谈

- 一手资料：
  - Brandon Sanderson 官网《Sanderson's First Law》原文（hard/soft magic 分野）。
  - Brandon Sanderson 官网《A Definitive Guide to Sanderson's Laws of Magic: Lecture Notes #7》（BYU 创意写作课讲稿）。
- 拆解类：
  - Symban《Building a Magic System That Holds Across Ten Books — The Five Questions》（把三定律操作化为五问，含 power-creep / cost-drift 诊断）。
  - The Obsidian Tavern《Magic Systems: How to Build One That Strengthens a Story》（"grow the understanding, not the raw power"）。
  - Squibler《How to Create a Magic System That Holds Up》（三定律修订测试）。
- 范本作品：
  - 《诡秘之主》（爱潜水的乌贼）：硬规则+代价+扮演法。
  - 《凡人修仙传》（忘语）：森严境界、锯齿成长、越级极难。
  - Sanderson《mistborn》（迷雾之子）：金属魔法系统的硬规则范本。
- 反面教材拉片：
  - 《龙珠Z》那美克星篇后战力曲线（看数值如何失控）。
  - 《权力的游戏》后几季（规则与人物战力随剧情漂移的另一类崩坏）。
