# 文体适配：用途、媒介与语域

任务分派统一见 [routing.md](routing.md)。本文件只负责语言与格式适配，不另设入口；不能用表面关键词覆盖用户明确选择的文体。

## 四问判定法（先从已有信息回答）

1. 用途：叙事、抒情、解释、论证、协作、表演，哪一个主导？可以有次要功能。
2. 读者/观众：谁会读、听或观看，如何获得信息？长篇阅读与竖屏观看的节奏不同。
3. 载体与交付物：小说正文、文章、分场剧本、舞台台本、声音脚本、分镜、论文、邮件或规范文档？
4. 声音与事实边界：虚构还是非虚构，谁在叙述，用户希望保留怎样的语域？第一人称不是散文的必要条件。

这些是内部判断问题，不是每次都要抛给用户的问卷。只有信息缺失会改变作品方向时才问；否则保留原有语域。

## 维度路由表

| 文体/产品 | 优先保留 | 常见编辑方向 | 不应机械套用 |
|---|---|---|---|
| 小说/网文 | 视角、人物声音、因果与承诺 | 让场景和选择推进故事 | 每章必须战斗或强钩子、所有句子短化 |
| 影视文学剧本 | 场号、时空、可呈现动作、台词与声音 | 心理外化、场景目标与变化 | 默认英文场头或按小说段落判断格式 |
| 舞台/广播剧 | 可表演/可听信息、出入场或声场 | 使观众能识别行动与空间 | 禁一切独白或旁白、只写画面线索 |
| 诗歌/散文诗 | 意象关系、声音、形式选择 | 炼字、重复的变化、停顿 | 情节闭合、比喻固定配额、句长分数 |
| 歌词 | 唱法与乐句边界、记忆点、可听重复 | 检查重复是否服务传唱而非冗余 | 用阅读诗的"重复必须带位移"标准判副歌啰嗦；把押韵密度当缺陷；要求它承担文本层信息密度 |
| 旧体诗词/曲与对联 | 用户指定的谱本、韵书体系、句读与对仗契约 | 逐字按可查表核验后指出不合处 | 把某一套韵系统当唯一正确标准；用口诀或自动计数代替核验；以"降低工整感"破坏已有形式 |
| 散文/随笔 | 观察、思考与个体声音 | 去空泛议论、调整详略 | 必须第一人称、必须开放结尾、虚构亲历 |
| 记叙/特稿/非虚构 | 来源、时间关系、引文与事实 | 找回材料已有细节、区分事实与推断 | 凑感官、补不存在的采访或见闻 |
| 议论文/评论 | 争点起点、材料与授权句、真实让步与反驳、可核具体物 | 删无依据的评价壳、集中主线、修正虚假二选一 | 把敏感句式当禁用词表、逐句撒缓冲词、为结构造对手、按考场扣分口径制造排比 |
| 学术期刊/会议论文 | 问题、方法、证据、不确定性、引用与刊物稿约 | 使语言强度与证据闭合相配、具体化论述、删重复 | 口语化、强加立场、把有依据的限定当模糊删掉、把被动当缺陷删 |
| 研究生学位论文 | 本校现行稿约、可核查性、跨章一致、引用双向闭合、工具使用披露 | 分章核信息一致与局限交代、术语与编号一致 | 套用"不设字数由交付契约决定""允许留白抒情"等小说侧默认；把格式检测通过当学术通过；用小说台账管论文 |
| 技术/法律/公文 | 定义、条件、责任、编号与可执行性 | 在授权范围内澄清歧义 | 为降分拆步骤、去术语、改法律含义 |
| 商务/邮件 | 请求、责任人、时间与礼貌程度 | 明确下一步、压缩冗余 | 一概去客套、擅改承诺或期限 |
| 演讲/口播 | 听觉节奏、转折与例子、场合语域 | 适合换气和听众信息处理 | 删除全部路标、把重复一律当错误、**把称呼串／致谢串／校训收束等礼仪套语当 AI 味删掉**（空洞感来自缺少可核查的具体小事，不是来自套语形式） |
| 新媒体/评论 | 论点、事实与目标读者 | 更快进入重点、准确标题 | 虚构热点细节、夸大标题承诺 |

篇幅和对白比例只能作线索。短文本不自动等于邮件，有参考文献不自动等于学术，对白多不自动等于小说；未知文体不默认散文。

## 混合文体

按段落或场景的实际功能分配编辑方式。技术科普可以有叙事开场，纪实文章可以有议论，但各部分仍需遵守事实边界。小说改剧本、剧本转小说属于改编，执行 routing 的改编流程。

## 冲突仲裁顺序

1. 用户明确目标与事实、引用、原作限制。
2. 交付用途和明确的稿约/格式。
3. 人物、因果与连续性。
4. 可读性、作者声音和必要的风格毛边。
5. 可选技法与静态 lint 提示。

明确的改写请求已经允许修改用户交来的稿子；不另设真人文字绝对不改的门槛。用户明确要求口语稿、广播稿等，就按目标语域转换；未要求时保留原语域，不因降分自行跨档。

## 逐条 tell 的保护条件表

| 结构 | 值得修改的情况 | 应保留的情况 |
|---|---|---|
| 首先/其次/最后、编号列表 | 把没有层次的文字硬拆成三点 | 操作步骤、责任分工、听觉路标 |
| 因此/然而/此外 | 与实际关系不符、重复空转 | 真实因果、转折与补充关系 |
| 否定前项肯定后项、递进与对称句 | 否定项无依据；把可并存项写成排斥关系；虚设低劣对手；两端同义或无功能重复 | 有依据的纠错、概念排除、必要比较和服务人物立场的修辞；详见[对照与句段节奏](argument-and-rhythm.md) |
| 专业词、行业词 | 找不到对应行动/对象、堆词遮蔽信息 | 精确术语、必要定义、人物口吻 |
| 平行句、对偶与重复 | 为凑对仗新增空话或虚假分工；只换词重说；每段套同一骨架而挤掉内容 | 条款比较、人物强调、母题回响、对联或用户明确要求的整齐形式 |
| 被动与多层定语 | 主干被压住、指代不清 | 明确受事、责任或必要条件 |
| 总结结尾 | 重说一遍且拔高无依据 | 论文结论、行动决议、阶段收束 |
| 长句、破折号、省略号 | 阻碍理解或节奏失控 | 叙事声音、语气与停顿需要 |

判功能与上下文，不以词语出现一次定错。

## 改稿契约（需要时简记）

写明文体/读者、目标语域、事实或设定边界、必须保留项、改动范围和交付格式。小任务可在内部确认，不必输出表格。用户样本可提供语气参考，不能以像样本为由改事实或抄内容。

## lint 文体门控与数字边界

支持 general/tech/academic/official/law/email/speech/fiction；具体选择与退出码见 [editing-workflow.md](editing-workflow.md)。剧本和诗歌没有专属标定，不强套 fiction。历史单篇标定不等于通用阈值，也不代表作者身份判断能力。实测记录在 [research-basis.md](research-basis.md)。
