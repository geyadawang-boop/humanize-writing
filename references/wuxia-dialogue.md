# 武侠对白腔调参考（称谓三分法 / 切口春典 / 四大家风格 / 现代技法翻译）

本文件管**武侠壳里的对白怎么开口**——半文半白的称谓体系、切口与仪式化套路、四大家对白风格。与既有文件的分工：武侠世界观/门派/武功/侠义/江湖设计在 wuxia-craft.md；通用对话技法（潜台词、话轮、action beat 的完整版）在 dialogue-craft.md；句层文风在 by-genre.md「小说/网文」节。核心立场：武侠腔 ≠ 文言文，而是"武侠外壳 + 现代对话内核"。

## 一、核心方法论

### 1. 半文半白称谓体系：自称 / 对称 / 他称三分法

- **自称（贬低自己以抬人）**
  - 平辈谦称：在下、鄙人、不才、晚生、小可。
  - 对长辈/前辈：晚辈、后学、弟子、末学。
  - 门派掌门/帮主：老夫、本座、本舵主（对下属时居高临下）；对平辈掌门仍可称"在下"。
  - 官府中人：本官、下官、本县（县令自称）；对上司称"卑职"。
  - 僧道：贫僧、贫道、小僧、小道；高僧可自称"老衲"。
  - 女子：奴家、小女子、妾身；女侠对同辈可用"我"，不必处处"奴家"。
- **对称（抬举对方）**
  - 平辈男性：兄台、阁下、足下、尊驾、朋友。
  - 前辈/高手：前辈、老英雄、大侠、宗师、方丈、道长。
  - 晚辈/少年：贤弟、少侠、小友、娃娃（长辈居高临下时用）。
  - 女性：姑娘、女侠、夫人、小姐、师姐/师妹。
  - 不确定身份时的万能开场："阁下尊姓大名？""阁下高姓大名？"
- **他称（谈对方家人用"令/尊/贤"，谈自己家人用"家/舍/拙/贱"）**
  - 称对方父=令尊/尊大人；母=令堂；子=令郎；女=令爱/令嫒；妻=尊夫人/贤伉俪。
  - 称自己父=家父/家严；母=家母/家慈；妻=拙荆/贱内/内人；子=犬子；女=小女；弟=舍弟；妹=舍妹；家=寒舍/敝处。
  - 问年龄：问对方年轻=贵庚；问长辈=高寿；问自己（被问时谦答）=虚度二十有五。
- **身份差异速查**
  - 掌门/帮主：对下属摆架子用"本座""本帮"；对江湖平辈收回去称"在下""敝帮"。
  - 江湖散人/游侠：自称"在下""小可"，不摆辈分，用词最活。
  - 官府：咬文嚼字、官话，"本官""岂有此理""拿下"。
  - 僧道：寡言、机锋、禅意，"阿弥陀佛""善哉""施主"。
  - 女子：女侠可飒（"我偏要管"），闺秀可柔（"但凭吩咐"），切忌所有女子都捏着嗓子"奴家"。

### 2. 江湖规矩式对白：切口与仪式化套路

- **切口/黑话（又称"春典""唇典"）**——底层江湖、绿林、镖局、丐帮用语，
  士大夫与正派掌门一般不说，只在黑店、绿林、拜码头时出现。
  - 风紧（风声紧、情况不妙）+ 扯呼（撤走、快跑）= "风紧，扯呼！"
  - 并肩子 = 并肩作战的兄弟，即"弟兄们"。
  - 点子 = 盯上的目标/敌人；"点子扎手"= 这对手厉害。
  - 春点/春典 = 黑话本身；"泄漏春点"= 自泄身份。
  - 青子 = 刀；"亮青子"= 拔刀。
  - 踩盘子 = 事先踩点探路。
  - 注：以上多源自连阔如《江湖丛谈》记录的北平江湖春典，
    经评书、《智取威虎山》与武侠小说反复使用；
    具体某词首次进入武侠小说的确切回目，多数待考，写作时按"常见用法"处理。
- **仪式化对白四类套路**
  - 拜码头：先报名号 → 自谦 → 递帖子 → 对方"久仰" → 试探来意。
    例："在下游方姓X，今日拜山，只求贵寨借道/借宿一晚，绝不敢犯贵地规矩。"
  - 约战：约时、约地、留话、不偷袭。
    例："阁下既要讨教，三日后子时，土地庙后槐树下，不见不散。""赵某若不到，任阁下处置。"
  - 谢罪：自报罪名 → 甘愿领罚 → 不劳动手/自行了断一截手指。
    例："是在下有眼无珠，错伤了贵派师兄，要打要杀，绝无半句怨言。"
  - 决裂/绝交：断义、划地、从此恩断义绝。
    例："你我今日割袍断义，今后路归路、桥归桥，再见面便是敌人。"

### 3. 四大家对白风格速查

- **金庸：庄谐并重、文白夹杂、对话里带文化典故。**
  叙述端用白话，人物开口时有书卷气；不同阶层人物腔调拉开差距。
  粗人（萧峰、鲁智深式）句子短、理直气壮；书生（段誉、陈家洛）会引诗词。
- **古龙：短句、留白、断句、省略号；对话即推理，话不说明。**
  常以一两字一顿制造停顿和悬念；人物不把话说透，靠沉默与"……"撑张力。
- **梁羽生：书卷气最重，常整联整诗入对白；文雅、庄重、说教味偏浓。**
  人物开口常吟诗作对，诗词是谈情与比武的双面工具。
- **温瑞安：诗化、破格、标点实验；短句分行、意象堆叠、反复咏叹。**
  句子可以短到一两个字成段，用重复与节奏制造压迫感；
  缺点是容易被读者吐槽"骗稿费"，新手慎用。

### 4. 把现代对话技法"翻译"进武侠腔

- **潜台词**：心里想 A，嘴上说 B。
  现代写法："我没事。" 武侠壳："在下这条命，早不是自己的了，姑娘又何必多问？"
- **话轮（turn-taking）**：谁抢话、谁停半拍，就是谁占上风。
  武侠里用"冷笑""半晌不语""顿了一顿"替代现代的"打断道"。
- **信息差（dramatic irony）**：读者知道而角色不知。
  让 A 客气称"贤弟"，读者却知道 B 正是他灭门仇人。
- **Action beat（动作节拍）**：用一个小动作隔开两句话，替代"他说/她说"。
  现代写法：他攥紧拳头。武侠壳："他右手按上刀柄，指节微微发白，淡淡道……"
- **节奏**：吵架/动手前句子越写越短；抒情/叙旧时句子拉长。

## 二、原则 / 公式 / 检查项

### 写作原则
1. **七分白话、三分文言**：叙述和内心独白用现代汉语，
   只在开口台词里压一点文言虚词（矣、乎、哉、焉、耳）。
2. **人物分腔**：掌门、少侠、反派、僧道、女子、地痞，六张嘴要能闭着眼分出是谁。
3. **称谓跟着关系走**：陌生人最客气，熟人最随便，反目时把敬称反着用最扎心
   （"贤弟"变成讽刺）。
4. **黑话省着用**：一场戏里出现两三句切口即可，多了像背字典。
5. **信息藏在话缝里**：真正要紧的事不要让角色直接说破。

### 万能开场公式
- 试探来意："在下XX，江湖上朋友看得起，赏了个诨号叫XX。
  今日冒昧登门，不知阁下有何见教？"
- 拒绝邀请："盛情本不该却，只是在下尚有心事未了，不敢误了贵派大事。"
- 约战："阁下武功高强，在下心悦诚服。三日后此地，尚要向阁下再讨教三招。"

### 完稿检查项（逐条过）
- [ ] 全文搜一遍"搞定/OK/没问题/谢谢/拜拜/不好意思/麻烦你"等现代词，全删。
- [ ] 是否对晚辈、下人用了"令尊/贤弟"这种过度尊称？
- [ ] 是否所有角色说话一个味儿？（挑三段遮住人名，还能认出是谁吗？）
- [ ] 是否有连续三段以上全是文言长句，读起来噎人？
- [ ] 黑话是否超过读者能当场推断的密度？
- [ ] 称谓是否随关系变化而变化（结拜前"段兄"→结拜后"大哥"）？

## 三、正反例（均附出处）

### 正例1（金庸·庄谐并济）
《天龙八部》第二十回"悄立雁门 绝壁无余字"，乔峰对阿朱：
> 乔峰见她神色奇异，柔声道："阿朱，你有什么难言之隐，尽管跟我说好了。
> 咱俩个是患难之交，同生共死过来的，还能有什么顾忌？"
> 阿朱脸上又是一红，低低的道："没有。"
——分析：叙述白话，人物开口半文半白；
"咱俩个""还能有什么顾忌"是大白话，但"尽管跟我说好了"带江湖气，不酸。
（出处：古诗文网/5000言《天龙八部》全文站）

### 正例2（金庸·气势与典故）
《天龙八部》第四十一回"燕云十八飞骑 奔腾如虎风烟举"，萧峰斥慕容博：
> 萧峰道："不行！"……凛然说道："杀母大仇，岂可当作买卖交易？
> 此仇能报便报，如不能报，则我父子毕命于此便了。
> 这等肮脏之事，岂是我萧氏父子所屑为？"
——分析：短起句"不行！"炸场，接一句文言重话"岂可当作买卖交易"，
结尾"所屑为"三个字把人物脊梁立住。粗人不说粗话，反而掷地有声。

### 正例3（古龙·短句留白）
《多情剑客无情剑》（小李飞刀系列），李寻欢与阿飞对答：
> 阿飞道："既然迟早难免一战，你还考虑什么？"
> 李寻欢道："在这一个时辰中，我要先找到一个人。"
> 阿飞道："……"
——分析：每句都短，答非所问的留白比直接解释更有分量；
省略号不是偷懒，是把判断权交给读者。
（出处：古龙武侠网 gulongbbs.com 《多情剑客无情剑》第九/十二章）

### 正例4（梁羽生·诗词入对白）
《萍踪侠影录》张丹枫对云蕾吟朱淑真《中秋》：
> 张丹枫道："不许蟾蜍此夜明，今知天意是无情！
> 何当拨去闲云雾，放出光辉万里清！"
——分析：借古人诗句说自己心事，不直露；
这是梁羽生最典型的"以诗代白"。（出处：梁羽生家园论坛 yushengbbs.net）

### 正例5（温瑞安·诗化破格）
《四大名捕》系列常见句法：
> 无情冷冷地看着他。无情道："为什么？"
> 追命突然就睡了。
——分析：句子断到最短，名词+动作独立成句，像镜头切格；
不是用来讲道理，是用来"压节奏"。（出处：抖音/豆瓣读者摘录，温瑞安原著）

### 反例 → 修正对照

**对照A：现代腔穿越**
- ✗ 原稿："这事儿就交给我吧，保证给你搞定，没问题！"
- ✓ 修正："此事但放宽心，在下定然办妥，不劳阁下挂怀。"

**对照B：称谓错级（对晚辈用敬称）**
- ✗ 原稿：师父对徒弟："你这孩子，令尊要是在世，见你这副模样，怕是要叹气。"
  （徒弟是晚辈，提到徒弟父亲不必用"令尊"；师父自称也不该端着）
- ✓ 修正："你这孩子，你爹若还在世，见你这副模样，怕是要叹气。"
  （长辈对晚辈，直呼"你爹"反而亲；"令尊"留给你对平辈/前辈说话时用）

**对照C：全部角色一个腔调**
- ✗ 原稿：地痞拦住主角："阁下擅闯敝寨，莫非是瞧不起本寨主不成？"
  （地痞不该满口"阁下/敝寨/不成"，这是掌门腔）
- ✓ 修正：地痞："哪儿来的小子？敢在大爷的地盘上撒野，报个万儿！"
  （"报个万儿"=报个名号，地痞切口才对味）

## 四、书目与创作谈

- **金庸**《天龙八部》（三联版/新修版）——学人物分腔与文白节奏。
- **古龙**《多情剑客无情剑》《楚留香传奇》——学短句、留白、省略号。
- **梁羽生**《萍踪侠影录》《冰川天女传》——学诗词入对白与文雅腔调。
- **温瑞安**《四大名捕会京师》《逆水寒》——学诗化破格（精读，不要照抄）。
- **连阔如**《江湖丛谈》——真实江湖春典/切口的第一手记录，
  写作时查黑话以此书为准，不要自己生造。
- **网文公开素材**：豆瓣读书各书"原文摘录"页（按热度排序），
  是最快的逐句语感训练材料。
- **创作谈**：金庸《射雕》后记、古龙《多情剑客无情剑》代序
  （"一个人如果已经把自己完全投入于权力和仇恨中，
  怎么还能期望他还有梦？"），体会作者对"人说话的方式"的自觉。
