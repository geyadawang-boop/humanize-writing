# 能力、资料与按需阅读地图

先确定用户要改一段、写一个成品，还是持续完成整部作品，再读对应执行文件；出现具体症状时补读工艺文件。本页不是全库必读清单。

## 1. 能力与交付证据

| 任务 | 阅读入口 | 应交付实物 | 能力边界 |
|---|---|---|---|
| 润色、改对白、改场景 | genre-router；对应 craft | 约定范围的修订正文 | 不强加整部长篇建档 |
| 短篇/长篇小说从构想到完稿 | [novel-workflow.md](novel-workflow.md)；按症状查 novel-craft 分册 | 必要设定、全部章节正文、修订与完结记录 | 有执行框架；模板数量不证明故事成立或文学品质 |
| 电影/影视剧集完整初稿 | [screenplay-workflow.md](screenplay-workflow.md)、[chinese-screenplay-format.md](chinese-screenplay-format.md) | 总纲、分场/分集、全部正文、时长与结尾核验 | 不保证投拍、发行或商业成功 |
| 竖屏短剧、短片及其他短时长影像 | screenplay-workflow、中文格式 | 约定集数与时长内的完整故事 | 画幅、时长、商业模式分别判断；平台流量公式另核 |
| 舞台/广播/音频剧 | screenplay-workflow 媒介分支 | 可演/可听的完整正文与提示 | 复杂调度、声学、音乐、制作预算须专项补证 |
| 改编 | screenplay-workflow 改编步骤 | 取舍表、改编正文、变更记录 | 不是把叙述改成对白；公开发行等权利问题按实际项目另核 |
| 散文、诗歌、演讲、商务等 | genre-router；by-genre；对应 craft | 用户指定的完整文本 | 不套长篇章节表或影视节拍配额 |
| 专业/历史题材 | 对应 workflow + [content-boundaries.md](content-boundaries.md) | 正文、关键事实来源、待核项 | 虚构设定与现实事实分开；类型知识不能代替专业核实 |
| 投稿/备案/平台要求 | content-boundaries；当次原始要求 | 标明日期、地区、媒介、适用范围的核对记录 | 附件不是现行法律库，不承诺必过审、必签约、必爆 |

完整初稿至少意味着约定范围内每个章节/场次都有正文，核心承诺有结局，中段没有以提纲、占位符或重复前文充数。“修订稿”“可制作稿”“获专业审核”是不同状态，不能混称。

## 3. 何时补读

- 整部创作：对应 workflow → 当前批正文 → 状态维护；不要先通读全部 craft。
- 格式问题：中文格式；用户指定英文 spec、分镜或摄制本时，再查 screenplay-craft 的相关节。
- 人物动机、对白、伏笔、时间线：分别读 character-craft、dialogue-craft、foreshadowing-craft、timeline-craft，检查对象始终是正文。
- 专业场景：核实会改变该场因果的知识，不为知识“全面”加载无关百科。
- 影片数据、作者原话、法律/平台数字：回原始来源核本次适用范围；source-index/source-evidence 可导航，不能继承其旧标签为当前核验。

## 4. U3 题材卡

以下是对附件的编辑性归纳，不是观众心理定律。交叉题材只叠加必要检查。

| 题材 | 起草前明确 | 正文检查 | 不机械继承 |
|---|---|---|---|
| [校园/成长](campus-youth-craft.md) | 学段、年代、地区、校制、学生自己的目标 | 语言、日程、同伴关系；重要教育/心理事实另核 | 不强制升学或亲子和解为唯一落点；普通青春情感不一概排除 |
| 悬疑/推理 | 公平解谜、悬念惊悚或社会议题各自承诺 | 关键线索的首次出现、谁知道、误读与解释；公平解谜尤其可回溯 | 不要求每集反转；多时间线不等于 hybrid |
| 科幻/奇幻 | 核心假设、能力代价、现实科学与虚构边界 | 角色运用已铺设机制；高潮不临时增添万能解法 | 不强制前三集解释完设定；不固定大场面配额 |
| 历史 | 史实、架空或戏说，争议史料处理方式 | 时间/制度/称谓的关键依赖有来源，虚构连接有边界 | 单篇报道的创作主张不是所有历史题材的法律结论 |
| 都市/职业 | 职业任务、资源制约、生活条件 | 工作流程真正影响剧情并带来后果 | “至少一场工作”不是真实性达标线 |
| 家庭 | 关系历史、照料/资源/边界分配、各自目标 | 冲突有积累，变化有行动与代价 | 和解、分离、有限修复均可服务故事，不一律强制和解 |

## 5. 尚需按项目补足

具体补料优先级见[资料补充与验证](material-intake.md)。现有长篇资料已经涉及全书/分卷架构、中段、群像、支线、卷间承接、长期伏笔和完本，不能笼统说“没有长篇知识”。补编五已补充教程摘要、案例综述和教学修订对照；仍需区分它们与同一作品的原始计划—正文—改纲—修订版本链，以及多卷、多次恢复、长期更新和整书大修的实际验证。定长文学/类型长篇与滚动连载的执行重点分别见[小说工作流](novel-workflow.md)。

资料偏重网文、影视与局部工艺。非类型文学长篇、儿童分龄创作、喜剧表演验证、复杂舞台/音乐剧、音频制作、互动叙事、纪实采访与职业细节，不能凭目录宣称充分覆盖。先用通用流程开工，再补直接影响作品的专项来源与读者/演员反馈。

脚本能核文件、ID、范围和状态，不能判断人物是否可信、场面是否动人、谜底是否公平或结尾是否有余味。能力评价须同时看正文、结构对照与实际审读。
